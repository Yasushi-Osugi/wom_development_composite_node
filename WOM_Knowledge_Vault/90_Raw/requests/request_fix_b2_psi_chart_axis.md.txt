## 1. 症状

PSI Chart（Network タブ下部）で、**在庫（右軸）のゼロ点が
P/S（左軸）のゼロ点と揃っていない。**

在庫が全週ゼロのノードでは、matplotlib が描画対象の値域を取れず、
右軸が **±0.04 程度の微小レンジ**に自動設定される。

```
右軸の目盛例：0.04 / 0.02 / 0.00 / −0.02 / −0.04
```

その結果、**在庫ゼロの水平線が、棒グラフの中央あたりの高さに描かれる。**
左軸のゼロは下端にあるため、両者の基準線がずれる。

### 1.1 実際に誤読が発生している

- 2026-08-20：`apparel-us-2026` の `Factory_Import_CN` で「在庫が立っている」と誤読
- 2026-09-01：`bom-test-2026` の `Tire_Supply` / `Vehicle_Assy` で同じ現象を再度指摘

**同じ現象を、同じ人間が2度誤読している。**
「大杉さん以外が WOM を使う」場面では、より高い確率で誤解される。

### 1.2 中身は正常である

`bom-test-2026` の golden JSON で確認できる通り、値は正しい。

```
Tire_Supply     I_max 0, I_sum 0
Battery_Supply  I_max 0, I_sum 0
Vehicle_Assy    I_max 0, I_sum 0
DC_Vehicle      I_max 5, I_sum 100   ← OutBound だけ在庫がある
```

**計算は正しく、表示だけが誤解を生んでいる。**

---

## 2. 修正内容

**右軸（在庫）の下限を 0 に固定する。**

```python
ax2.set_ylim(bottom=0)
```

在庫は負値を取らないため、マイナス側の目盛は元々不要である。

これにより、

- 在庫が全週ゼロのノード → 線が**下端**（左軸のゼロと同じ高さ）に来る
- 在庫があるノード → ゼロ基準で高さが読めるようになる

### 2.1 対象箇所

`wom/gui/app.py` の PSI Chart 描画部分。

**PSI Chart 以外のチャート（Cost/Revenue、Buffer Stock、Harvest Input、
Capacity Chart 等）には触れないこと。**
それぞれ軸の意味が異なるため、一律に適用してはならない。

該当箇所を特定したら、**変更前に報告すること**（§5 手順①）。

### 2.2 上限の扱い

下限のみを 0 に固定し、**上限は matplotlib の自動設定に任せる。**

在庫が全週ゼロの場合、`set_ylim(bottom=0)` だけでは上限も 0 になり
軸が潰れる可能性がある。その場合の挙動を確認し、必要なら
上限に小さな正の値（例：1）を与えるなどの対処を検討すること。

**どう対処したかを報告すること。**
