# note 記事 rev.5 数値訂正パッチ ── 公開済み記事の4か所

対象: 公開済み記事「利益地形図で読み解く事業計画」
作成: 2026-09-11
理由: Phase 6-1（`true_optimum` の実計算化）の実装により、記事が引用していた真の最適解の値が**誤りだったことが判明**した。

---

## 何が起きたか（先に説明）

記事の数値は Phase 5 設計書 §2.3 の**手計算値**を引いていました。Phase 6-1 でこれを実行時計算に置き換えたところ、設計書の値と一致しませんでした。

調べると、**設計書の「真の最適解」は最適点ではありませんでした。**

```
設計書  JP=7   US=35,168  EU=16,825   → 103,881,757.5
実計算  JP=0   US=35,176  EU=16,824   → 103,891,296.0

差の内訳:  US  +8 lot × 2,077.5 = +16,620.0
          EU  −1 lot × 1,831.5 =  −1,831.5
          JP  −7 lot ×   750.0 =  −5,250.0
                                  ──────────
                                    +9,538.5
```

単位マージン 2,077.5 の米国の需要を 8 lot 残したまま、いちばんマージンの低い日本（750）に 7 lot 配っていた。**厳密に劣る点でした。** 丸め誤差ではなく、手計算の最適化ミスです。

**記事の主張は何も変わりません。** 差は 0.09% で、「貪欲法が閾値の手前で止まり、全体利益の約 10% を取りこぼす」という結論も、「下界は過大に出ない」という説明もそのままです。訂正するのは数値4か所だけです。

---

## 訂正箇所（4か所）

### C1. 「貪欲法はいつ間違えるのか」章 — 3行の表

**場所**: 「これをモデルに入れます。…結果はこうなりました。」の直後の表

**old**:
```
| **貪欲法（Merit Order）** | 16,825 lot | 93,824,700 JPY |
| 231格子の最良点 | — | 103,552,800 JPY |
| **真の最適解** | **35,168 lot** | **103,881,758 JPY** |
```

**new**:
```
| **貪欲法（Merit Order）** | 16,825 lot | 93,824,700 JPY |
| 231格子の最良点 | — | 103,552,800 JPY |
| **真の最適解** | **35,176 lot** | **103,891,296 JPY** |
```

変えるのは3行目だけです。**1行目と2行目は正しいので触らないでください。**

### C2. 同章 — 差額の金額

**old**:

**new**:
> 差額は **10,066,596 JPY**。全体利益の約 10% です。

---

### C3. 同章「経営的な含意」— 下界の被覆率

**old**:
> ここで表示される値は、正確には取りこぼしの**下界**——「少なくともこれだけは取りこぼしている」という値——です。上の例では 9,728,100 JPY で、真の取りこぼし 10,057,058 JPY の 96.7% にあたります。

**new**:
> ここで表示される値は、正確には取りこぼしの**下界**——「少なくともこれだけは取りこぼしている」という値——です。上の例では 9,728,100 JPY で、真の取りこぼし 10,066,596 JPY の 96.6% にあたります。

`9,728,100` は**変わりません**（貪欲法の解と格子の最良点から決まる値なので、真の最適解の訂正の影響を受けません）。

---

### C4. 同章末尾 — 実装状況の一文

Phase 6-1 が完成したので、この一文を現在形に直せます。**任意ですが、直したほうが正確です。**

**old**:
> なお、3つの利益水準のうち、貪欲法の解と格子の最良点は今日の WOM が計算します。真の最適解は、関税の崖の on/off を場合分けして各区間を線形問題として解けば厳密に求まることが分かっており（手計算で検証済み）、次のリリースで実装します。

**new**:
> なお、3つの利益水準は、いずれも今日の WOM が計算します。真の最適解は、関税の崖の on/off を場合分けし、閾値を配分量の上下界として制約に持たせたうえで各区間を線形問題として解くことで、厳密に求まります。
>
> 余談ですが、この機能を実装したとき、**それまで手計算で置いていた「真の最適解」が最適ではなかったことが分かりました。** 単位マージンの高い市場の需要を 8 lot 残したまま、最もマージンの低い市場に 7 lot 配る——人間が電卓で追うと、こういう見落としが起きます。地形図を描く目的のひとつは、まさにこれを機械に検算させることでもあります。

C4 を入れるかどうかはお任せします。**記事の主張を弱めるどころか強める**と思いますが、章が長くなるので、入れない判断もあり得ます。
