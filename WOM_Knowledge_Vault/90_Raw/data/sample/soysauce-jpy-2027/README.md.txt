# soysauce-jpy-2027（円建て・為替シナリオ版）

国産醤油の対米/対欧輸出ケースの **JPY 建て（base_currency=JPY）** 版。`soysauce-eu-2027`（S2＝全6市場）をベースに、
**円安（対ドル 150→200 円/$）** と **輸入原料・石油由来樹脂のコスト高**を織り込んだ為替シナリオを表現する。
匿名化方針は他ケースと同じ（企業名を出さず「国産醤油」で統一。数値は例示）。

## USD 建てケースとの違い
| 観点 | soysauce-us/eu-2027 | soysauce-jpy-2027（本ケース） |
|---|---|---|
| 報告通貨 base | USD | **JPY**（`ppc_fx_rate.csv` の base_currency 列で自動検出） |
| 為替 | フラット（JPY→USD=0.006667 固定） | **時系列**：2027=150円/$、2028=200円/$（W01–W04ランプ）。EUR=USD×1.08 連動 |
| 輸入原料コスト | USD 建て（FX不感） | **USD 建て → 円安で JPY コスト増**。原油リンクのスパイク付き |
| 国内加工費 | USD | **JPY 建て（FX中立）**：醸造/瓶詰 ¥750、国内倉庫/DC ¥75/¥150 |
| 海外DC費 | USD | 現地通貨（US=USD、EU=EUR）→ 円安で JPY 増 |
| CCC | dso6/dpo8（=−2週, 前受け） | **dso8/dpo6（=+2週）**：買掛支払6週 < 売掛回収8週の運転資本負担 |

## モデル化した「為替×地政学」の綱引き
- **輸出売上**（US $40 / EU €38）は円換算で **円安が押し上げ**（$40×150=¥6,000 → ×200=¥8,000）。
- **輸入原料**（大豆・樹脂・包装材、`Materials_JP` USD $6/lot）は **円安で JPY コスト増**（$6×150=¥900 → ×200=¥1,200）。
- **原油ショック**：`ppc_supplier_cost.csv` で輸入原料 USD 原価を 2028-W10 に $6→$8（Hormuz型・樹脂/包装材高）、W26 に $6.5 へ部分残存。**円安期（2028）に重なり二重ショック**。

## 為替2水準の見方（デモ）
別フォルダを増やさず、**時間軸で 150 vs 200 を対比**：PPC コックピットの週フィルタで
**2027-W01〜W52（150円regime）** と **2028-W05〜W52（200円regime）** を切替え、GM・円売上・円原価の差を読む。

## 確認ポイント（GUI）
1. 起動時に `[PPC B2] base_currency auto-detect` が **JPY** になること（CLI ログ）。
2. PPC/Management の金額が **円建て**で表示され、2027→2028 で輸出円売上↑・輸入原料円原価↑の綱引きが出ること。
3. 2028-W10〜 で原料原価スパイク（樹脂/原油）が上乗せされること。
4. Management の **CCC ≈ +2.0週**（買掛先行の運転資本負担）。
5. Landed Cost（関税 Base/10/0）は台帳ソースで円建て・lot精度のまま。
