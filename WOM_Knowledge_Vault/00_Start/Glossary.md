# 用語対応

| 用語 | 本保管庫での意味 |
|---|---|
| Data Building | データ構築・モデル定義 |
| Optimization on Demand Allocation | 需要配分最適化。主要機能として独立 |
| Planning | 週次PSI計画と実現性計算 |
| Evaluation | 物量・金額・経営指標の評価（Eveluattionの表記を統一） |
| Presentation | 表示・帳票・比較図 |
| Management Cockpit | 意思決定手順をまとめる操作面 |
| Composite Node | 複数PSIと制御イベントの組合せという設計概念。新クラス導入と同義ではない |
| CO | 未履行の要求。物理的な在庫ではない |
| actual | 計画Sとは区別する実行量。経路ごとの算出方法を確認 |
| WIP | 工程内在庫。今回の同週kit完成近似で独立状態は新設していない |
