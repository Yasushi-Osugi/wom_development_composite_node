# 最初の事業計画比較（タイの投入時期の 2 案）— 現行 WOM との対応表 v0.1

- 作成：Claude君（設計担当）、2026-11-13。依頼：大杉さん・GPT君（ロードマップ案 §3 の到達点 2）
- 基準：`wom-v1r6m0_BS-SEAF`、`1814788`
- 調べ方：コード・サンプル・既存の報告を読んだ。**実行はしていない**。「見込み」と書いた所は、Code君の実行で確かめる
- 関係する文書：[ロードマップ案 v0.2](../docs/design/drafts/Roadmap_WOM_Management_Cockpit_Product_Market_v0.2.md)、[金額基盤の棚卸し表](WOM_MoneyBase_Inventory_v0.1.md)

## 一言で

**2 案の比較は、ほぼ現行の WOM で組める。新しく要るのは、エンジンの外に置く小さな道具が二つだけ：「投入の表から週別需要を作る道具」と「2 案の結果を並べて差をたどる道具」。** 計画・配分・金額のコードは変えない。固定費は WOM に入れず、「案の順位が逆転する週固定費」を比較の道具が計算する。

## 1. 経営上の問いと 2 案

> **今の供給能力でタイに早く入ると、追加で得られる利益に対して、どの市場でどれだけ供給を失うか。**

| | 後期案（基準） | 早期案 |
|---|---|---|
| タイの代理店の販売開始 | 2028-W01（今のサンプルのまま） | それより早い週（**大杉さんが決める**。たたき台：半年早い 2027-W27） |
| ほかの条件 | シンガポールの 3 チャネルの開始週・定常の需要・価格・販促・能力・計画期間・配分の方針・金額の規則は、2 案で同じ | 同じ |
| 製品 | クリーム（`COS_Cream`）1 製品。美容液は今のまま流す（工場の能力は SKU ごとの行なので、クリームの比較に混ざらない） | 同じ |

注意：**早期案は需要を「ずらす」のではなく「足す」**。タイで売る期間が延びるので、需要の合計が増える（たたき台の 26 週なら、クリームで約 78 lot）。能力が足りなければ、不足の合計も増える見込み。

## 3. 4P の入力の表（たたき台）

1 行 ＝ 製品 × 市場・チャネル。モデルの写しのフォルダに置く（名前の案：`market_entry_plan.csv`）。

| 列 | 意味 | 初回の扱い |
|---|---|---|
| `sku_id`, `region` | 製品と、需要の販売先・チャネル（`demand_forecast.csv` の `region` と同じ鍵） | 使う |
| `launch_week` | 販売開始の週 | **案ごとに変える**（タイだけ） |
| `steady_lots_per_week` | 定常の需要 | 2 案で同じ |
| `ramp_weeks`, `ramp_ratio` | 立ち上がりの週数と比率（今は 13 週・0.5） | 2 案で同じ |
| `price`, `currency` | 市場の価格（Price） | 記録だけ。金額は今までどおり `ppc_market_price.csv`・`vc_price_rule.csv` が正本。食い違ったら道具が止める |
| `promotion_note`, `basis_note` | 販促の前提（Promotion）と、数量の根拠 | 記録だけ |

道具の出力：`demand_forecast.csv`（全週・全鍵、開始前は 0）と、入力の表・版・作った行数の記録。**需要は外から人が置いた数字ではなく、この表から作ったものだと辿れるようにする。**

## 4. 試行の進め方（Code君に渡すときの骨子）

1. **基準の再現**：道具に今の開始週を入れ、今の需要 CSV と同じものが出ること。C3a の写しで、既知の結果（注文残 192・売上・試算利益）が出ること。
2. **2 案を配分なしで実行**：後期案（＝ C3a）と早期案。どの市場・どの週に不足が出るかを観測する（6 の (a)）。
3. **大杉さんが守る供給水準を決める**（§5）。
4. **2 案を同じ配分の方針で実行**（6 の (b)）し、金額まで出す。
5. **比較**：週別の需要・供給・未充足・在庫・年齢・売上・コスト・試算利益。差の出た週から、代表の lot で理由をたどる。順位が逆転する週固定費。
6. 能力を足す効果は、**同じ投入週で能力だけを変えた追加の案**で切り分ける（必要になったら）。

合格の条件（GPT君の案のとおり）：**投入週の変更から、週別需要・供給不足・試算利益の差までを、たどって説明できること。** どちらの案が勝つかは合格の条件にしない。

## 5. 大杉さんに決めていただくこと

| 一言で | 中身 | 推奨 |
|---|---|---|
| 早期案の投入週を決める | タイの代理店の販売開始。たたき台は 2027-W27（半年早い） | 2027-W27 |
| まず配分なしで不足の出方を見る | 守る水準を決める前に、2 案で「今の WOM だと、どこに不足が出るか」を観測する（§4 の 2） | 見てから決める |
| 守る供給水準は、観測の後に決める | どの市場・どの週を守るか。たたき台は採用済みの方針（最低供給量 5 割、タイのクリーム 7 割、能力に合わせて後ろの週から削る）を 2 案に同じく当てる | 採用済みの方針から始める |
| 評価の指標 | 報告期間（2027-W01〜2029-W52）の累積の試算利益（固定費を引く前）、あわせて期末の未充足・在庫・製品の年齢 | この組合せ |

## 6. 現行 WOM で表せないもの（今回は扱わない）

- 4P の価格・販促が需要の量を変える効果（初回は投入週だけ）
- 週固定費の計上（比較の道具の計算で代える）
- 能力を足す投資の費用と時期（追加の案で能力だけを変えて切り分ける）
- 失われる需要（今は未充足が期末まで注文残として残る。小売に近い「買われずに消える需要」は表せない）
