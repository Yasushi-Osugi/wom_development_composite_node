## 0. 目的

Management が数量で決めた配分を、Backward → Forward に渡し、意味体系の ①〜⑤ が業務の意味どおりに分かれて記録されるかを確かめる（三層設計 MD §7.2 の P1：「元需要 → 採用配分 → Backward 配置 → Forward 納品の対応を追えるか」）。

| 数量 | 意味（`docs/semantics/supply_allocation.md` §3） |
|---|---|
| ① | 元の需要 |
| ② | 供給対象の需要（配分済み） |
| ③ | 未配分の需要（経営が対象にしないと決めた量） |
| ④ | 実納品（当週・前倒し・遅配） |
| ⑤ | 配分後の未充足（期末の注文残。計画の結果） |

**一番の見所**：配分の合計を能力の合計にそろえたとき、⑤ が 0 になるか。0 にならないなら、どの鍵・どの週に残るか（週ごとのピークと先行生産の深さ。対応表 Q07）。

## 4. 見込み（仮説。外れても止めない。外れたら理由を調べて書く）

- **P0** は C3a と同じ数（数量配分モードの V09）。
- **P1**：③ ＝ タイ 104・88。② の合計は能力の合計と同じなので、Backward の前倒しが計画の最初の週にちょうど収まり、**⑤ ＝ 0** になると見込む。作り置き・年齢は C3a と同じ程度（能力の上限いっぱいで作ることは変わらない）。
