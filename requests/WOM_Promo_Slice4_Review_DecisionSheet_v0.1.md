# 追加販促（試行 1〜4b）の区切りの判断票

## 0. 一言で

**GPT-MC君の推奨は「追加販促の業務上の採用は保留のまま。増産を何週確保して既存の需要をどこまで回復するかを先に決める。販促の変換・評価の仕組みの検証はここで区切る」。** 数字・読み方とも報告書と一致しており、Claude君として直す所はない。

## 1. メモの要点（Claude君の要約）

- 同じ長さの増産だけに足す販促の価値：25% 反応は +6,072 円（店舗費用が避けられなければ −127,236、半分なら −60,582）、50% 反応は約 +37 万円（同 約 +10 万円）。どちらも、増産だけなら届けられた 2029 年の既存需要（他の市場と EC 自身で 6・12 lot）との交換。
- 増産だけを延ばす価値は、確保費・保有費を引いても正（12 → 18 週 +78 万円、→ 24 週 +151 万円。低）。今回の範囲では止めどころは観測していない。止めどころは「延ばすほど良い」ではなく、回復目標・応援元の余力・実見積・品質・資金・2029 年の需要の確かさで決める。
- 店舗費用の「避けられない（0%）」は一律の悲観ケースではない：販促の比較では利益を下げ、増産の比較では利益を上げる。
- 守る供給の 1 lot の未達は、判定の許容 0 lot のまま「3/4」と記録する。許すなら対象・期間・量・理由を大杉さんが明記する。
- 経営者に示す表は「増産の長さを選ぶ列」と「同じ枠に販促を足す列」に分ける（メモ §7）。

## 2. 判断票

| # | 一言で | 中身 | 推奨 |
|---|---|---|---|
| E1 | **追加販促の業務上の採用は保留のまま** | 25% 反応を前提にした案は候補から外し、50% 反応の案は「供給を守る手段と、実際の反応・費用が確かめられたら」の条件つき候補として残す。反応の率を経営の選択肢にしない | はい |
| E2 | **増産は「24 週」を今回試した中の有力な候補として記録する** | 最適な期間でも実際の発注期間でもない。回復目標・応援元の余力・実見積・品質・資金・2029 年の需要の確かさを確かめてから決める | はい |
| E3 | **守る供給の判定は許容 0 lot のまま** | 販促＋延ばした増産（18・24 週）は 3/4 と記録する。1 lot を許す場合は、対象・期間・量・理由を明記して別に決める | はい |
| E4 | **店舗費用は 100%・50%・0% の 3 つの表示を続け、実際の内訳の確認を並行する** | 50% を採用値にしない。確認するのは、35% の費目の内訳・固定と変動・変更の期限（2029 年の該当週まで）・本部配賦・二重計上 | はい |
| E5 | **販促の変換・評価の仕組みの検証は、ここで区切る** | 翻訳 → 変換 → 計画 → 比較 → 追跡、市場別・週別・費用の感度・守る供給の判定・同じ長さの対照が揃った。経営コックピットのロードマップに到達点として記録する（Claude君）。業務の採用の未決は、再開の条件とともに残す | はい |
| E6 | **次の題材は「製品の投入週」（価格は据え置き）** | GPT-MC君の推奨。投入の表（`market_entry_plan.csv`）のある案への変換（変換の定義 v0.2 §4.2 で次の版に回した経路）を作る機会にもなる。供給を守る販促案（メモ §9 の P1）は、業務の採用に必要になったときだけ | はい |

> **大杉さんの判断（2026-11-24）：E1〜E6 をすべて推奨どおり採用。** 区切りの記録はロードマップ v0.5（`docs/design/drafts/Roadmap_WOM_Management_Cockpit_Product_Market_v0.5.md` 冒頭）に書いた。

## 3. 区切りの記録として残すこと（E5）

- 分かったこと：同じ販促でも、能力の条件で効き方が変わる（余裕：利益にそのまま出る／不足：時期と市場をまたいだ供給の交換／不足＋増産：利益を大きく動かすのは増産の長さ）。
- 未確認のこと：反応の実際（純増・反動・チャネル間の移動・継続）、確保費の実見積と延長枠、店舗費用の実態、2029 年の需要の確かさ、供給を守る配分の実現性。
- 販促の採用を再開する条件：メモ §4 の「販促を足す条件」1〜5。
