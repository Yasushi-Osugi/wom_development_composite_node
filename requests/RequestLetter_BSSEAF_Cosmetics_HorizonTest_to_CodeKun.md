## 4. Part B：期間を延ばす試験（Data だけ）

### 4.1 写しの作り方

- 元：正式サンプルから C3a の写し（シナリオの文書の手順）。
- 需要：2030-W01 から 13 週・26 週、鍵ごとに 2029 年の定常の週と同じ量（美容液：直営店 4・EC 3・代理店 SG 6・TH 4、クリーム：3・2・5・3）。
- 能力：同じ週に C3a と同じ行（美容液 17／14、クリーム 13／11、`source`＝`plan`）。
- 写しは案ごとに別に（`output/bsseaf_cosmetics/H_E13_A0e` など 4 つ）。

### 4.2 数量枠（能力に合わせて決め直す）

- SKU ごとの供給の対象の合計 ＝ B1 で固定した数え方の、良品の平準化の上限の合計。
- 直営店・EC は全量。代理店の間は、P2-a2 と同じ規則（貢献利益が僅差の組の中は需要に比例、最大剰余法）。P2-a の付録の `make_allocation.py` の P2-a2 の手順を、合計だけ変えて使う。
- 作った数量枠のファイルと、合計の計算の内訳を付録に置く。
- 手計算の目安（判断資料 §2.3）：外す美容液 156（E13）・208（E26）、クリーム 127・166。違っても止める理由ではない（B1 の数え方で決まる）。違えば理由を書く。

### 4.4 測ること

**共通の期間の比べ方（GPT君の条件）**：元の期間と重なる要求週 2027-W01〜2029-W52 の需要について、**同じ需要の集合・同じ判定の時点**で比べる。当週の納品はそのまま比べる。期末の未充足を比べるときは、まず**判定の時点を 2029-W52 にそろえた値**（共通の期間の需要で、2029-W52 までに届かなかったもの）を出し、延ばした期間の期末（2030-W13・W26）の値は別に示す。

| # | 測ること |
|---|---|
| H1 | A3 の減らす区間の**始まりの週・終わりの週・長さ**（SKU・代理店ごと）。E0・E13・E26 で並べる。A0e は減らした週の分布 |
| H2 | 共通の期間の要求週ごとの選択（②）と当週の納品。E0 との差がある週の一覧 |
| H3 | 共通の期間の代理店の充足率（前半〜2029-W20 と後半 2029-W21〜W52、週の最低） |
| H4 | 未充足（2029-W52 にそろえた値と、延ばした期間の期末の値）、時間の可否の参考値（条件 2 つ、試行の前に出す）、年齢の最大、作り置きの最大 |
| H5 | 外す量（③）の合計と、週の分布。B1 の数え方での数量枠の内訳 |
| H6 | 評価の額（P2-a と同じ式・単価。固定費の相当額は期間で変わるので、**共通の期間だけの値**と、延ばした期間全体の値を分けて、式を書く） |

まとめの表：期間（E0・E13・E26）× 規則（A0e・A3）× {外す量、減らす区間（始まり・終わり・長さ）、共通の期間の当週の充足率（全体・代理店）、未充足（2029-W52 にそろえて／期末）、参考値、年齢の最大}。
