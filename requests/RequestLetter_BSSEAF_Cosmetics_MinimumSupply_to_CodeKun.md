## 1. 決まっていること

- モード 1：SKU × チャネルの数量枠は P2-a2 のまま。代理店の間の数を変えない。期間は今の期間（〜2029-W52）。
- 最低供給量：代理店ごと（SG・TH）・製品ごと・要求週ごとに、**元の需要 × r を切り上げた lot**。r は 0.5 と 0.7。元の需要が 0 の週は対象外。
- 強さ：必ず守る（`required`）。
- 確かめ方は二段階：計画の時（選んだ ② ≥ 最低供給量）と、実行の結果（その要求週の**当週の納品** ≥ 最低供給量）。
- 削り切れない分は前の週へ広げる。
- 両立しないときは止めて、衝突と選択肢を添えて戻す。**衝突は、数量の不整合によるエラー（止める理由）とは分けて記録する**。

## 3. Part A：最低供給量を持つ選び方

### 3.1 方針のファイル `udp_policy.csv`（詳細設計 §2.2 の形）

今回使う列：`policy_id, policy_version, sku_id, region, min_supply_ratio, min_supply_rounding, min_supply_kind, reason`。

- `min_supply_rounding`：`ceil`（今回）／`floor`。`min_supply_kind`：`required`（今回）／`target`（記録のみ。今回は使わない）。
- 書かれていない鍵は「最低供給量なし」。空欄に既定値を黙って置かない。
- 今回のファイル（付録に置く）：4 行（美容液・クリーム × SG_Distributor・TH_Distributor）、r＝0.5 と 0.7 の 2 ファイル。

### 3.2 規則の変更（`trim_to_capacity_latest` に方針を渡せるように）

- `select_mode1_capacity(..., policy_file=None)`。`policy_file` が無ければ、今と同じ結果。
- 後ろの週から削るとき、各鍵・各要求週で削れる量の上限を **「その週の需要 − 最低供給量」** にする。上限で削り切れない分は、**さらに前の週へ広げて**削る（その週の能力を超える分 e(p) が 0 の週でも、外す量が残っていれば、最低供給量を守る範囲で削る。前の週の削りは作り置きで吸収される）。
- 鍵の外す量（数量枠で決まる）を、期間の全部の週で削っても置ききれないときは**衝突**とする。

### 3.3 衝突の記録（エラーと分ける）

- 出力 `udp_conflicts.csv`：`sku_id, region, quota_cut_lots, placeable_cut_lots, unplaceable_lots, min_supply_ratio, rounding, reason`。
- 選べる代わりの案を、文として一緒に書く：最低供給量を下げる／数量枠を見直す（チャネルの間の配分を選び直す次の段階）／能力を足す。
- 衝突があるときは、**その案の計画をエンジンに渡さない**（採用・次の工程へ回さない）。`udp_plan.json` の `calc_status` は「計画の前に止めた（衝突）」、`consistency_status` は「整合」（数量の誤りではない）、`target_status` は「未達（衝突）」。終了コードは、数量の不整合（今の `diagnostics/`）と区別できるものにする。
- 衝突の無い SKU・鍵の選択の台帳は出力してよい（参考）。

### 3.4 実行の結果での確認（二段階の二つ目）

- 出力 `udp_min_supply_check.csv`：`source_demand_ref, min_supply_lots, q2, on_time, plan_ok, delivered_ok`。
- まとめ：鍵ごとに、計画の時に下回った週の数（0 のはず）、実行の結果で下回った週の数と、その週の一覧。

### 3.5 テスト

| テスト | 中身 |
|---|---|
| 既定の不変 | 方針のファイルが無いとき、今の能力対応案と全行一致 |
| 上限と広げ方 | 小さな合成の例で、各週の削りが上限を超えず、削り切れない分が前の週へ広がることを手計算と照合 |
| 衝突 | 外す量を置ききれない例で、衝突の行と代わりの案が出て、エンジンに渡さず、終了コードが数量のエラーと違う |
| 二段階の確認 | 選んだが届かない例（合成）で、`delivered_ok` が偽になる |
| 方針の読み込み | 書かれていない鍵は「最低供給量なし」。不正な比率・端数の指定は止める |

回す段：途中は `--smoke` と `--area allocation`、最後に `--full` を 1 回。
