## 4. 実装（差分だけ）

### 4.1 D1：取引条件の表（新しい任意のファイル）

`vc_trade_terms.csv`（無ければ今のまま）。1 行 ＝ 区間 × SKU：

| 列 | 意味 |
|---|---|
| `edge_id`, `product_id` | 物理の区間と SKU |
| `incoterm` | 記録用の名前（例 `CIF`）。計算には使わない |
| `freight_borne_by` | `seller` か `buyer` |
| `freight_in_price` | `1`（価格に含む）か `0` |
| `note` | 根拠 |

受け付ける組合せ：`seller`・`1`（CIF。今回の改修）と、`buyer`・`0`（今の動きを明示したもの）。それ以外は読み込みで止める（今回は表せない）。ほかに止める条件（`MasterError`、ファイル・行・値と直し方）：列の不足、重複、物理の区間でない、その区間の売り手と受け手が連結の中の別々のグループの法人でない（法人間取引でない）、その区間に運賃の行（`ppc_edge_cost_rule.csv` の `logistics_cost`）が無い、その区間に保険の行（`insurance_cost`）がある。

`policy.py` の docstring の表に 1 行（「運賃（法人間の区間、取引条件で売り手負担・価格に含む）：売り手の、法人間売上に対応する原価。受け手の法人の原価に足さない。グループの原価には足す」）。「第 1 回では扱わない」の注記を直す。

### 4.2 D2：計上（`ledger.py` の `_edge_costs`）

表で `seller`・`1` の区間・SKU の出荷では、運賃の行（`freight`）を次のように分ける。週は出荷の週（今のまま）。
