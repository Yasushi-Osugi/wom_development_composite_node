**販促の試行（1〜4b）は区切りました（大杉さん 2026-11-24、判断票 E1〜E6 をすべて採用）。次の題材は、GPT-MC君の推奨どおり「製品の投入週（価格は据え置き）」です。** 打ち手（4P の Product）を、業務の問い・比べる案・需要の仮説・費用・評価の範囲として定義してください。成果物は §5 の業務定義メモです。

## 2. すでに分かっていること（到達点 2 の観測。化粧品、能力不足の C3a、金額は試算・円）

> **注**：下の数字は、2026-11-13 の実行での観測値です。押し戻し方の既定を比例（`proportional_week`）に変える前の実装・配分方式・費用の範囲で得たもので、**今回の受入の値にはしません**。Claude君が今の版との違いを確かめ、新しい比較の基準を定めます。GPT-MC君に実行し直してもらう必要はありません。

| 条件 | 早く入る（2027-W27）− 遅く入る（2028-W01） |
|---|---|
| 今の能力・配分なし | 利益の差 0。タイの要求週の入れ替えだけ（早い 78 lot が届く代わりに、2028 年末〜2029 年の 78 lot が届かない） |
| 今の能力・タイを守る方針 | 利益の差 ＋109,512。不足はシンガポールの代理店へ移る |
| クリームの計画の生産量を週 1 lot 上げる（早く入る案・遅く入る案の両方で） | 報告期間の連結試算利益の差 ＋8,854,560。早く入った分の需要が全部届く。**投入の費用・増産の確保費を引く前の差** |

つまり「投入週だけを変えても、能力が足りなければ利益は動かず、供給の入れ替えになる」は、販促と同じ形で既に見えています。**今回は同じ比較を繰り返すのではなく、業務の問いとして何を新しく決めるかを定義してほしい**、というのがこの依頼の中心です。

## 3. WOM の今の作りで、業務の前提になっていること（定義の材料）

- 投入の表の 1 行は「製品 × 市場・チャネル」ごとに、投入週・定常の需要（lot／週）・立ち上がりの週数と倍率・価格・通貨・メモを持つ。投入前の需要は 0、立ち上がりの期間は定常 × 倍率、その後は定常。
- **今のモデルは、投入前の自社の需要を作らず、その期間の販売の機会を投入後へ繰り越さない仮定である**（需要を作る段階の仮定で、すでにあった顧客の注文が消えたと観測したものではない）。投入を待つ顧客がいる場合は、待つ割合と期間を別の需要の仮説として定義する必要がある。
- 比べるときは、両案とも同じ報告期間（2027-W01〜2029-W52）で見る。遅く入る案の需要を後ろへずらす仮説にするなら、報告期間の末を超える需要の扱いも要る。
- 投入にかかる費用は、今の比較に入っていない。比較の道具が今読めるのは「週額 × 有償の週数」を利益から引く形だけ（案の費用の前提 `fixed_cost.csv`）。性質の違う費用をこの形にどう対応づけるかは、GPT-MC君の定義を受けて Claude君が決める。
- 価格は据え置き。価格と弾力性は、業務定義ができるまで扱わない（GPT-MC君のメモ §8）。

## 4. 定義してほしいこと

| # | 一言で | 中身 |
|---|---|---|
| Q1 | **経営者は何を決めたいのか** | 既存のクリームのタイ市場への投入に絞った問い（§0 の例を出発点に）。守る供給の条件と、評価に含める費用を明記する。複数の市場の投入の順番や、新しい製品と既存の製品の能力の取り合いは、今回は扱わない |
| Q2 | **比べる案は何か** | 案の数は最少に。基準と、同じ条件で投入週だけ変えた対照を必ず置く |
| Q3 | **遅く入ったとき、その前の需要はどうなるか** | 市場の潜在の需要・自社に発生する需要・供給できなかった需要の三つを区別する。参入していない期間の販売の機会を、そのまま未配分や未充足として数えない。そのうえで、作らない（今の仮定）／投入後へ一部が繰り越す（待つ割合・期間）のどれを前提にするか。繰り越すなら報告期間の末を超える分の扱いも |
| Q4 | **投入にかかる費用は何か** | 下の表の三つに分け、負担する法人・通貨・発生の条件・計上する期間・額の仮置き（低・中・高）を定義する。既存の原価・広告費・保有費との重なりを示す。タイの販路の週固定費の採用済みの定義から、引き継ぐ部分と足す部分を分ける。実装上の表し方は Claude君が対応づける |
| Q5 | **何を評価に入れるか** | 利益（報告期間の連結）、外部の費用、保有費、市場別・週別の実納品、守る供給の判定の要否。販促の試行で使った見方のうち、引き継ぐものと外すもの |
| Q6 | **代表週・代表数量の期待結果** | Code君が実行の前後で照合できるよう、1〜2 の代表の週と数量で、期待する結果（または期待の幅）を書く |
| Q7 | **しないこと** | 価格・弾力性、チャネル間の移動の推定、新しい配分の規則など、今回の範囲の外 |

Q4 の費用の分け方：

| 区分 | 例 | 定義してほしいこと |
|---|---|---|
| 一時の費用 | 初期の登録、取扱いの開始、初回の制作 | 発生の条件・週・総額 |
| 続く費用 | 販路の運用、追加の要員・設備の枠の確保 | 有償の開始・終了の週・週額 |
| 在庫・資金 | 初回の在庫の取得、資金の拘束 | 在庫の原価・売上の原価・保有費との関係 |

**初回の在庫の取得額を、既存の原価の計算とは別に投入の費用として全額引くと、二重計上になりうる。** 在庫として持つ金額、売れたときの原価、持つことに伴う費用を分けて定義してください。
