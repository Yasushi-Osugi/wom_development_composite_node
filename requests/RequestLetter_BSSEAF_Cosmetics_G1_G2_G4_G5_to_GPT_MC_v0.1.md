## 3. 論点別の依頼

### G1：売上の何%かと、1個いくらかを分ける

- **M0の観測**：Value Chainでは売上比率の費用が計上されず、同じ行にあった個数比例の配送・梱包費も落ちました。M0の未計上額は281,015,748円で、このうち配送・梱包は6,243,120円です（§6・T12）。
- **最初の計算例**：`SG_EC` のクリーム24個、税抜131 SGD/個（M0で平均値引き反映済み）。売上比率の項目は販社販管費10%、決済・EC基盤手数料5%、デジタル広告15%。個数比例の項目は配送・梱包3 SGD/個。各項目を分け、シンガポール販社の費用として記録する条件と、SGDでの計算を示してください。
- **決めたいこと**：どの売上を料率の基準にするか（この例の税抜価格・値引きの扱い）、何を根拠に何週で計上するか、配送だけが先に起きる場合に配送費をどう扱うか。売上・配送がそれぞれ対象にならない場合も示してください。入荷と販売で同じ費用を二度数えないことを確かめられる形にします。
- **直営店への適用**：店舗運営費35%と販社販管費10%の内訳を明記してください。35%はM5で採用した試行上の近似です。週固定費の定義や、配分で使う変動費の判断は別の課題です。

### G2：販促の対象と、費用を負担する法人を分ける

- **M0の観測**：代理店向けMDFの設定はありましたが、Value Chainでは費用にも問題の一覧にも出ませんでした。M0の未計上額は22,196,148円です（T12）。
- **最初の計算例**：G3と同じSG代理店向けのクリーム `COS_Cream:SG_Distributor:2028-W29:00002`。卸売は2028-W28に税抜1,488 SGD、MDFの試行料率は5%。この卸売を算定基準にする案では、どの法人が誰に対する費用を負担し、いくらをどの週に記録するかを示してください。SGはシンガポール販社、THは日本本社が負担するというM0の前提も確認してください。
- **決めたいこと**：卸売の成立で負担が確定するのか、販促実施・請求等の別の証拠が必要か。G3で決めた売上週と、MDFの計上週が同じになる条件を明記してください。今回は販促費としての試算を出発点にし、売上の控除など別の扱いが必要になる条件は契約の違いとして示してください。
- **確認条件**：G1の費用や代理店自身の費用と混ぜず、同じ卸売を代理店の受入・その先の出荷・PPCの集計でもう一度数えないこと。負担があるのに金額や根拠が取れないケースの扱いも示してください。

### G4：タイ向けの課税価格を、法人間の取引価格と区別する

- **M0tの観測**：PPC・Value Chainとも、6,000／5,000円/個を基準に30%を掛けました。T14の比較では、海上運賃70円/個を足す試算にすると税額は21円/個、全体で347,256円増えます。
- **最初の計算例**：日本から `DC_TH` へ送るクリーム24個。M0の0%とM0tの30%の試験条件を使い、基準額5,000円/個だけの場合と、運賃70円/個を含める場合の課税価格・税額を示してください。30%は感度試行の条件です。
- **決めたいこと**：`DC_TH` は日本本社の拠点です（M8）。M0tで「振替価格」を計算に流用したことと、法人間売買があることは別です。この移動に使う**試行上の課税価格の根拠**、運賃・保険を含める範囲（価格に含む場合は重ねて足さない）、負担法人、計上事象・週、通貨と丸めを定義してください。不明な費用の扱いは条件付きにします。実際の適用税率や課税評価は、モデルの仮定と区別し、扱う場合は公式資料・適用条件・時点を示してください。

### G5：運賃の負担と、在庫原価への算入を区別する

- **M0の観測**：`WH_JP_Released → DC_SG` の運賃60円/個が、法人間価格に上乗せされてシンガポール販社の在庫原価に入りました（全期間4,848,480円、T15）。試行の契約仮定は、日本本社が海上運賃を負担し、法人間価格に含めるCIFです。
- **最初の計算例**：クリーム24個、運賃込みの法人間価格5,000円/個、海上運賃60円/個。日本本社の外部運送業者への負担、販社の受入価額、連結で残る外部運賃を分けて示してください。受入価額に同じ運賃をもう一度上乗せしないことを、数で確かめられるようにしてください。
- **決めたいこと**：支払・負担法人と、費用・在庫原価の計上先・週をどう区別するか。出荷・受入・販売が別の週になる例で、どの週にどの法人の在庫原価・費用に残るかを示してください。運賃を誰が負担するかと、商品に対する支配がいつ移るかは、別々に前提を記録します。

## 4. 各業務定義書に入れる内容

| 欄 | 記載内容 |
| --- | --- |
| 適用範囲 | 化粧品の経営シミュレーションで何を表すか。対象法人、相手先、区間・チャネル、SKU、期間。外部報告の会計処理を扱う場合は根拠と範囲を別記する。 |
| 業務ルール | 算定基準、料率・単価、数量と単位、通貨、負担法人、根拠事象、計上週、計上する明細の種類と件数。発生、支払、在庫原価を必要に応じて分ける。 |
| 根拠と状態 | 現行の観測、採用済みの仮定、今回の提案、未確認を区別する。採用済みでも、実行確認の有無は別に書く。 |
| 手計算の期待結果 | 代表1ロットについて、入力 → 計算 → 法人・週・明細の種類・件数・金額を示す。計上する例と、計上しない例または二重計上を見抜ける例を各1つ。確認できる「0」、対象外、記録不足で判定できない場合を分ける。 |
| 照合と確認範囲 | 業務上の取引と、根拠となる出荷・売上等の記録をどう結び付けるか。ロットに複数の費用が立つ場合は費目も示す。再計算と実績の再取込・訂正は区別する。PPCは参照する週と集計単位を示した照合用の値とする。 |
| 大杉が決めること | 選択肢、推奨案と理由、選ぶと期待結果がどう変わるか。結論を左右する前提が欠けていれば、条件別の結果か未決を示す。 |

化粧品では、費用が無いことが確定している区間・ノードは明示の0を置く方針です（M7）。今回の定義では、費用があるはずなのに料率や記録が得られない場合を、費用なしと区別してください。
