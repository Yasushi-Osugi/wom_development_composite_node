# 索引の読解試験：Start Here から供給配分の知識に辿り着けるか

- 版：v0.1（2026-10-26）
- 作成：Claude君（Knowledge Curator）。実施の判断：大杉さん
- 目的：BS-SEAF の誤り E4「知識はあるのに見つけられなかった」への打ち手（Start Here §0.1・R20・R21、意味体系、対応表）が効いているかを確かめる（意味体系 README §5）
- 対象の版：`docs/WOM_Start_Here.md` を含む、試験を始める時点の `wom-v1r5m1_cap_trial` の先頭（実施の記録に SHA を書く）

## 1. 実施の手順（大杉さん）

1. **経緯を知らない新しいセッション**を開く（Claude Code、または GPT君の新しい会話。リポジトリを読めること）。このプロジェクトの chatlog・過去の会話・メモリは渡さない。
2. 下の §2「試験を受ける AI への指示」を、**そのまま**最初のメッセージとして渡す。ほかの文書・ファイル名・ヒントは渡さない。
3. 返ってきた回答を、そのままファイルに保存する（例：`docs/development/WOM_IndexReadingTest_<実施した AI>_<日付>.md`）。
4. Claude君が採点の表（別の文書。試験の後に commit する）で採点する。採点の表は、試験を受ける AI が読めないように、試験が終わるまでリポジトリに入れない。

複数の AI（例：Claude Code と GPT君）で別々に受けてもらうと、索引の効き方の違いも分かる。

## 2. 試験を受ける AI への指示（ここから下を、そのまま渡す）

---

あなたは WOM（Weekly Operation Model、週次の PSI 計画を作る Python のツール）のリポジトリを初めて読む担当者です。リポジトリは `wom-v1r5m1_cap_trial` のブランチです。

**ルール**

- 最初に `docs/WOM_Start_Here.md` を読み、そこから辿ってください。ほかの入口から探し始めないでください（Start Here から辿れなかったときは、そのあとで自由に探してかまいません。その場合は「Start Here から辿れず、〇〇で探した」と書いてください）。
- コードを実行する必要はありません。文書とコードを読むだけで答えてください。
- 各回答に、**根拠にしたファイルと節**を書いてください。
- 分からない、または文書に書かれていないときは、推測で埋めずに「見つからない」と書いてください。
- 最後に、**読んだファイルを読んだ順に**すべて並べてください（どこで迷ったかも）。

**問い**

問 1. 供給が足りないとき、ある市場 A に 100、市場 B に 100 の需要があり、B は 50 だけを供給の対象にすると決めた。計画の結果、対象にした 150 はすべて期限内に届いた。このとき「未配分」と「配分後の未充足」はそれぞれいくつか。B の残り 50 は、いつ届くことになっているか。

問 2. ある期間の実納品を数えるとき、その期間に出荷した量をそのまま実納品としてよいか。よくないなら、なぜか。

問 3. 化粧品のシンガポール展開の試行で、タイの代理店を足したケース（C3a）で出た期末の注文残 192 lot は、経営が供給の対象から外した量か、それとも別の量か。

問 4. 化粧品のモデルで、価格や原価をまだ置いていない段階で、「チャネルごとに供給する数量を人が決めて計画したい」。
  (a) 業務として、この判断に金額の情報は要るか。
  (b) WOM には、そのための既存の仕組みがあるか。あるなら何で、使う前に何を確かめるか。
  (c) 以前からある、比率で配分を渡す経路をそのまま使うと、化粧品では何が問題になるか。

問 5. WOM の計画の結果から「期末の注文残」の lot 数を数えるには、何を使うか。最終週の注文残（CO）や、毎週の CO の合計を使ってよいか。

問 6. 計画期間の終わりに不足が残った。これは恒常的な能力の不足だと言えるか。何を調べて判断するか。

問 7. 化粧品の試行 P1 では、配分の合計を能力の合計にそろえたのに、注文残が 4 lot 残った。これは業務の欠品として扱うか。なぜ残ったか。

問 8. WOM の「能力の層（Capacity Layer）」の結果にある `unallocated` は、供給配分の意味体系でいう「未配分」と同じか。化粧品に当てはめる前に何を確かめるか。

問 9. 「配分」の定義は、業務として採用されているか。それは誰がいつ決めたか。化粧品で実際に動かして確かめたか。

問 10. 供給配分について、業務の方針として**まだ決まっていない**ことを挙げよ。
