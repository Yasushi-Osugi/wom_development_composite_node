# 会計とサプライチェーン・シミュレーションをつなぐ WOM の知識体系と初心者向けガイド

## 0. 一言で

**経営の打ち手（価格・投入・増産・配分など）が、週ごとのロットの動き（WOM 数量編）を通って、売上・原価・費用・利益（WOM 金額編）にどう出るか。それが財務会計（法人別の損益・連結）と管理会計（製品 × 市場の採算・意思決定の差額）でそれぞれどう見えるか。** この一本の筋を、経営者と経営学を学ぶ学生が腹落ちする言葉で説明できる知識体系と初心者向けガイドを作り、WOM が「それを業種を問わず CSV だけで組み立てられるシミュレータ」であることと合わせて、広く知らせる。

## 1. 目的：誰が、何に腹落ちするか

| 読み手 | 腹落ちしてほしいこと |
|---|---|
| 経営者 | 「この打ち手で、どの市場に何週に何ロット届き／届かず、利益がいくら動くか。それは決算（法人別・連結）ではこう見え、事業の採算ではこう見える。未確認の前提はこれ」と、自分の言葉で説明できる |
| 経営学を学ぶ学生 | 教科書の会計（財務会計・管理会計）と SCM が、1 ロットの動きでつながることを、手を動かして確かめられる |
| コンサルタント・実務家（第二の読み手） | 自社・顧客の構造を CSV で組み、同じ筋で検証できる。業務の定義と照合の手順を再利用できる |

## 2. 課題の定義：今、何が足りないか

| # | 課題 | 今の状態 |
|---|---|---|
| P1 | **会計の言葉と SCM の言葉が分かれている** | 財務会計は「法人・期間・取引」、SCM は「品目・週・ロット」で考える。WOM はその橋（ロット → 取引 → 法人別の損益 → 連結の消去）を持つが、橋の説明がない |
| P2 | **WOM の機能と会計の概念の対応表がない** | 例：PPC は管理会計（製品 × 市場の採算）に近く、Value Chain は財務会計（法人別の取引・移転価格・関税・連結の消去）に近い。案の外の費用（確保費・維持費・保有費）は意思決定の差額。この対応がどこにも一枚で書かれていない |
| P3 | **6 つのテーマが別々に作られ、別々に確かめられた** | 価格・E2E のコスト構造・Value Chain・関税・移転価格・連結は、化粧品の G1〜G5、金額基盤の棚卸し、PPC と Value Chain の照合などで個別に定義・検証済み。知識は設計書・報告書・業務定義に散らばっている |
| P4 | **初心者向けの語り口がない** | 今ある文書は開発者・設計者向け（依頼書・報告書・業務定義）。経営者操作ガイド（docx）は操作の説明で、会計との関係は扱っていない |
| P5 | **「カスタマイズ・フリー」を示す見せ方がない** | 16 の正式なモデル（化粧品・醤油・米・石油・スマートフォンなど）がコードを変えずに CSV だけで動く事実はあるが、読み手に伝わる形になっていない |
| P6 | **できないことの線引きが外に見えない** | 例：貸借対照表・資金繰りは未整備（比較値 A は Net Cash ではない）、週固定費は案の外、関税・移転価格は架空のサンプルの規則で税務の助言ではない。知識体系の信頼は、この線引きの明示にかかる |

## 3. 知識体系の骨格（提案）

### 3.1 三つの層と、層をつなぐ原則

| 層 | 中身 | 会計との関係 |
|---|---|---|
| A 経営の問い（コックピット） | 何を決めるか。案を作り、比べ、差の理由をたどる | 意思決定会計（差額の比較、境目、感度） |
| B WOM 数量編 | 二つの木（需要と供給）、需要の単位としてのロット、PSI、能力・配分・押し戻し、需要の三つの名前（①〜⑤） | 売上・原価が「いつ、何個」生じるかの源 |
| C WOM 金額編 | 価格・原価・費用の置き場所（ノード・区間）、PPC、Value Chain（法人・取引条件・移転価格・関税・連結の消去）、案の外の費用 | 財務会計（法人別・連結）と管理会計（製品 × 市場、差額）の両方の数字 |

層をつなぐ原則（例。体系の中で根拠つきで整理する）：

- 1 ロットの外部への出荷は、売上と売上原価を一度だけ生む（支配の移転の週で数える）。
- グループ内の取引は法人別の損益には出るが、連結では消える。連結の利益とグループの在庫は移転価格を変えても変わらない（変わるのは法人別の利益と、関税の課税価格を通じた税額）。
- 管理会計の採算（PPC）と財務会計の連結（Value Chain）は、同じ規則なら一致し、違うなら違いの出どころ（規則・区間・週・法人）を示せる。
- 未設定の金額は 0 にしない（未評価として出す）。費用は二重に数えない。
- 案の比較は、同じ版・同じ条件の対照と比べる。

### 3.2 テーマごとの章の型（6 テーマ共通）

| 節 | 中身 |
|---|---|
| 1. 経営の問い | このテーマで経営者が決めたいこと |
| 2. 財務会計では | 法人別の損益・連結で、どう見えるか |
| 3. 管理会計では | 製品 × 市場の採算・意思決定の差額で、どう見えるか |
| 4. WOM 数量編では | どのロット・週・能力が関わるか |
| 5. WOM 金額編では | どのファイル・列・規則で表すか（PPC・Value Chain・案の外の費用） |
| 6. 例題 | 化粧品などの既存の試行から（架空のモデル）。代表の 1 ロットを手計算でたどる |
| 7. 落とし穴と、できないこと | 実際に起きた誤り、未整備の範囲 |

### 3.3 6 つのテーマと、使える既存の材料

| テーマ | 既存の材料（例） |
|---|---|
| 価格 | 市場価格と通貨（`ppc_market_price.csv`・`vc_price_rule.csv`）、4P の翻訳表。価格の変更と弾力性は業務定義が未着手 |
| E2E のコスト構造 | ノード・区間の費用、売上に比例する費用（G1）、販促協力金（G2）、運賃の置き場所（R8）、smartx の原価の直し、増産の確保費・保有費の業務定義 |
| Value Chain との関係 | 法人の割り当て・取引条件・連結の消去、PPC と Value Chain の照合（税率 0% で差 0） |
| 関税シミュレーション | 課税価格の定義（G4）、国境の区間、税率 30% の感度で残った差 |
| 移転価格税制 | `ppc_transfer_price_rule.csv`、法人別の利益が動き連結は不変という性質、CIF の運賃の負担（G5） |
| 連結会計 | 内部取引と未実現利益の消去、グループ在庫、報告通貨と為替 |

## 4. 成果物と段階

| 段 | 成果物 | 使い道 |
|---|---|---|
| S1 | **体系の目次と用語の対応表**（会計の用語 ↔ WOM の概念・機能・ファイル・列）。正本は Markdown でリポジトリに置く | 以後のすべての章・ガイド・公開物の土台 |
| S2 | **テーマ別の章**（6 章、§3.2 の型）。既存の業務定義と報告から起こし、例題は手計算で照合する | 知識体系の本文 |
| S3 | **初心者向けガイド**（平易な語り口、1 テーマ 1 本、図つき） | 経営者・学生の入口 |
| S4 | **公開**：note の連載、WOM Academy のレッスン、学術の論文、動画の構想（下書きにある） | 広く知らせる |

S1 → S2 は最初の 1 テーマで型を作り、残りは同じ型で増やす。S3・S4 は、章が照合を通ってから起こす（公開の後に数字の誤りが見つかると、信頼を損なうため）。

## 6. 気をつけること

- 公開のリポジトリなので、実在の企業・団体・製品の名前を書かない（Start Here の落とし穴 11）。
- 関税・移転価格・連結は、架空のサンプルに採用した規則での説明であり、税務・会計の助言ではないと各章に明記する。
- 「できないこと」（貸借対照表・資金繰り・週固定費の本格的な扱い・価格弾力性の推定など）を、章ごとに隠さず書く。
- WOM はスタンドアロンの Windows で動く（企業の機密を扱うため）。公開物でもこの前提を示す。
