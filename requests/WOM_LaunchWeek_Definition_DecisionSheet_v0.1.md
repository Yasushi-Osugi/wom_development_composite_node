# 製品の投入週（タイのクリーム）の業務定義の判断票

## 0. 一言で

**GPT-MC君の推奨は「タイのクリームを 2028-W01 に入れる案と 2027-W27 に入れる案の二つを、同じ能力・価格・需要の作り方で比べる。守る供給を満たさなければ、利益だけで早期投入を選ばない」。** 照合の結果、止める理由はない。

## 1. Claude君の照合（現物と算術）

| 項目 | 結果 |
|---|---|
| 遅い案の需要（299 lot：2028 年 143・2029 年 156、2028-W13 まで 2・W14 から 3） | 正式サンプルの `demand_forecast.csv` の該当行と一致 |
| 早い案の需要（377 lot、差 78 ＝ 2027 年 65 ＋ 2028 年 13） | 需要を作る規則（各週の四捨五入）で一致 |
| 費用の低・中・高（一時の費用＋週額 × 104／130 週） | 全部一致。週額 4・5・6 万円は、採用済みのタイの販路の週固定費の定義にある説明用の値 |
| 一時の費用の週（投入の 2 週前：2027-W25／2027-W51）、卸売の小例（76,800 THB ＝ 345,600 円、4.5 円／THB）、保有費の小例 | 一致 |
| 道具 | 案の投入週を変える操作は、コックピットの案の道具にすでにある。一時の費用は「有償の開始＝終了の週」の 1 行で今の費用の前提に表せる |

**申し送り（Code君への依頼書で扱う）**

- 遅い案の基準は、今の既定（押し戻し方の比例）で**実行し直して取る**。2026-11-17 に作った案 C01 の結果は、既定を変える前のものの可能性がある。
- 今の能力のまま 78 lot の需要を足すと、比例の押し戻しではクリームの不足がシンガポールの市場にも分かれやすい。**二案だけの比較は「守る供給は未達、早期投入は保留」と出る見込みが高い**（旧版では不足がタイ自身に留まった）。L9 はこのための判断。
- 美容液は能力も計画も製品ごとなので、クリームの投入週では変わらない前提（基準の時点で美容液の不足が複数の市場に分かれているのは比例の押し戻しによるもので、今回の影響ではない）。比べる案どうしで美容液の結果が同じことを確かめる（GPT君の指摘 2026-11-25 で訂正）。

## 2. 判断票

| # | 一言で | 中身 | 推奨 |
|---|---|---|---|
| L1 | **最初は、投入週だけが違う二案で比べる** | 2028-W01（基準）と 2027-W27。能力は不足の条件のまま、配分の方針は置かない | はい |
| L2 | **投入前の需要は作らず、待っていた顧客の繰り越しもしない** | 今の作りのとおり。市場に需要が無い・失注が無いと認めるものではない | はい |
| L3 | **立ち上がりの規則は両案とも同じ** | 定常 3 lot／週、13 週は半分（四捨五入で 2 lot） | はい |
| L4 | **守る供給は、今回の基準案（遅い案）の実際の納品で決める** | タイのクリーム以外の 7 つ（シンガポールのクリーム 3 チャネルと美容液 4 チャネル）と、タイの 2028〜2029 年の継続分。期間合計で 1 lot の不足も許さない。販促のときの下限の値は使わない | はい |
| L5 | **一時の立ち上げの費用を、週額と分けて 1 回だけ計上する** | 日本本社の負担、投入の 2 週前。10・30・60 万円は検証用の仮置き | はい |
| L6 | **販路の維持費の週額は、試行用の幅（4・5・6 万円）で見る** | 採用済みの定義どおり、実際の週額は未設定のまま | はい |
| L7 | **在庫の保有費は今までの方式で見る** | なし・年率 5・10・15%。初回の在庫の取得額を、別に費用として引かない（二重計上になる） | はい |
| L8 | **追加の増産・倉庫の契約は置かない初回にする** | 明示の 0。要らないと確かめたという意味ではない | はい |
| L9 | **増産した場合の一対も、同じ依頼で続けて回す** | 両案に同じ増産（到達点 2 と同じ「クリームを全期間で週 1 lot」）を置いた一対を、二案の結果とは分けて報告する。二案だけでは「供給の入れ替え」で終わる見込みが高く、経営の問い（いつ入るか）に答えるには増産と組み合わせた比較が要るため。GPT-MC君は「次の比較」に回す推奨だが、分けて報告すれば投入週の効果と増産の効果は混ざらない | はい（Claude君の追加。GPT-MC君の案は「二案の後に別途」） |
