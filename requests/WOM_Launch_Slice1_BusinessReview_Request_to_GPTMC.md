## 3. 評価してほしいこと

| # | 一言で | 中身 |
|---|---|---|
| C1 | **増産なしで早く入る案を、どう扱うか** | 試算利益は減り、SG の供給も守れない。採用の候補から外すか。外すなら、その理由を経営の言葉で |
| C2 | **早く入るなら増産が前提、と言ってよいか** | 増産ありの一対の結果と、確保費の水準（低・中・高）での答えの変わり方。大杉さんの以前の見立て（今の要員の応援＝低・中）との関係 |
| C3 | **増産の期間をどう決めるか** | 全期間で置いた増産を、早く入る分の需要に合わせて期間を絞る試行が要るか。要るなら、どの週から何週か（業務上の根拠と、検証用の仮置き）。以前の答え「期間を絞った案は安いが余裕が無い」とどう両立させるか |
| C4 | **販路の維持費の境目を、どう読むか** | 境目 約 32〜34 万円／週は、仮置きの 4〜6 万円／週よりずっと高い。経営者にどう示すか。実際の維持費の確認で何を確かめればよいか |
| C5 | **まだ確かめていないことは何か** | 需要の仮説（立ち上がりの強さ、投入前の需要を作らない仮定）、費用の実額、2029 年の需要の確かさ、守る供給の対象の妥当性など。結論を変えうる順に |
| C6 | **次にすること** | 期間を絞った増産の試行、別の題材への移行、ここでの区切り、のどれか。推奨と理由 |

## 4. 書き方のお願い

- 事実（報告書で確かめたこと）と提案（業務上の仮置き・解釈）を分ける。
- 数字は報告書から引き、新しい数字を作る場合は計算の式を書く。
- 大杉さんが決める点を、一言の表現と推奨つきで並べる。
- 早い案で増えた需要 78 lot は二つの需要の仮説の差で、「待っていた顧客」ではない。
