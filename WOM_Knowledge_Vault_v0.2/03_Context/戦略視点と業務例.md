# 戦略視点と業務例

## 5視点の使い方

記事06・07から得る判断の枠組み。次の対応はVaultの編集案であり、5つの実装済み画面の説明ではない。

| 視点 | 業務上の問い | WOMでの扱い方 |
|---|---|---|
| ASIS | 現状はどうなっているか | 実績・現状前提を入力し、モデルとの差を確認 |
| TOBE | どうありたいか | 目標案と計算上の最良案を区別して比較 |
| CANBE | 現在の制約で何ができるか | 能力・部材・週位置をPlanningで検証 |
| WILLBE | 今の条件を延長するとどうなるか | 成り行き仮説。S1のP_bauは需要比例配分という具体的近似 |
| LETITBE | 意図して変えないものは何か | 維持する条件を人が決める。専用状態実装は未認定 |

## 業務例

以下は機能を読むための利用手順であり、新たな計算結果ではない。

| 業務例 | 機能の読み順 | 確かめたい判断 |
|---|---|---|
| 米の季節供給 | 需要・カレンダー → Buffer → 在庫評価 → 経営課題 | 季節在庫と通年需要のつなぎ方、資金拘束 |
| EV部材遅着 | ネットワーク → Kitting → CO・actual → lot追跡 | 遅着後に需要を充足し、部材だけが消失しないか |
| 複数市場への供給 | Cost Master → 利益構造 → 配分 → handoff → PSI → PPC | 高採算配分を実行できるか。できない差は何か |
| 関税変更 | シナリオ → 価格・関税評価 → 配分感度 → 採用判断 | 市場順位や最適領域が変わるか |

背景記事の一覧は [[03_Context/記事と機能の対応表]]。
