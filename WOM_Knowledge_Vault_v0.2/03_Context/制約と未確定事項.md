# 制約と未確定事項

| 項目 | 現時点の扱い | 次に確認すること |
|---|---|---|
| 汎用Composite | Kitting回復は限定実装 | 混在子、BOM数量、完成品ID、期末残の範囲 |
| 加工中WIP | 同週kit成立＝完成という業務近似 | 工程内状態を追加するなら別要件 |
| P/S/I別cap | 汎用モデル完成ではない | 制約対象・単位・週位置の契約 |
| Kanban | 現場運用を週次計画が支えるという方針 | 消費連動補充実装とTW前倒しを分離 |
| TW Buffer 1350 | 業務由来は未確認 | 実効適用対象と由来の根拠 |
| 在庫保有費 | per_lot倉庫費と期間費は異なる | 評価目的に必要な保有費設計 |
| PPCと中間CO | 中間未充足が利益不変でも正常とは言えない | 販売入力・実出荷・中間保存の照合 |
| S4 Evaluate | 設計と全面実装を分ける | 画面・差異分類・受入条件 |
| 5戦略視点 | 概念として収録 | 実装状態名への機械的な置換を避ける |
| LLMとRL | 業務思想・将来展望 | 現行接続、状態・行動・報酬の契約は別確認 |
| 移転価格の説明 | docstringはcost_plusのみ、コードにはfixedも存在 | 正式文書の同期 |

機能ノート内の「関連実装あり」は、全例外で業務要求を満たしたという品質認定ではない。記事の記載だけで現行機能を実装済みにしない。
