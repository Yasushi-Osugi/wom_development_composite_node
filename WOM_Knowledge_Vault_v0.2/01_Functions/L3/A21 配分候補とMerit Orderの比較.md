# 配分候補とMerit Orderの比較

一案だけでなく、能力配分の選択肢と利益差を調べる。

**入力：** 配分比率、共通能力、市場需要、利益関数。

**利用結果：** 候補集合・最良候補・選択案。

**状態：** 関連実装あり・静的確認。実行保証の認定ではない。

**利用例・確認観点：** 採用点と計算上の最良点を区別し、探索粒度による差を説明する。

**注意：** 格子の最良点を任意条件での厳密大域最適と呼ばない。
