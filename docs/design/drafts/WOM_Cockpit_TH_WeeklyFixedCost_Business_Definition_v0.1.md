## 2. 販路維持費の発生条件（提案）

| 項目 | 提案する条件 |
| --- | --- |
| 費目 | **タイのクリーム販路の週定額運用委託費**。現地の代理店向け窓口を維持する外部サービスの対価を、数量・売上に依存しない1種類の費用として仮定する。 |
| 負担者・支払先 | `E_JP` がクリームの販路運用を外部の現地受託事業者へ委託し、支払義務を負う仮定。事業者名と契約の存在・金額は未確認。タイ代理店が自己負担する費用は連結試算の対象外。 |
| 発生の起点 | **契約上、販路の運用が有償になる稼働開始週**。代表例では、予定販売開始と有償稼働開始が同じISO週になる契約を仮定する。契約が稼働に先行する場合は、発効時点から有償かを契約で判定する。 |
| 開始・終了と販売ゼロ | 週定額の発生対象となる開始週と終了週を含める。有償稼働中は実売上・納品が0でも1週分を計上。無料週、契約外の週は0件。期中の開始・終了は契約が週額を課す週を特定する。この例は週単位の契約とする。 |
| 報告期間と支払 | 費用発生週をISO週に置き、報告期間に含まれる週を集計する。期間外に発生した週は別に把握し、比較額への算入は0円。請求締め・現金の支払週は別に記録する。 |
| 金額と計上単位 | 1案・1契約対象・1発生週につき `f` 円・1件。初回は共通の **JPY／発生週** を仮定する。案別にWOMの `P0` の下の別欄で控除する。同じ週に出荷や請求明細が複数あっても、同じ週定額の計上は1件。 |

既存のMDFは卸売額に応じる販売費。数量比例費用、一時の立ち上げ費、両案共通の本社費、在庫保有費も別の費目として扱う。この仮定の費用はクリームの販路を対象とする。実際の契約が美容液を含む共通のサービスなら、その契約の発生週と、クリーム投入によって追加で負担する範囲を先に確認する。[化粧品README M5・M6・G2][cos] ・ [棚卸し表 #7・#9][inventory]

**未設定と明示0円**。契約範囲・有償週・週額の未確定はそれぞれ「未設定」。有償週数が確定し週額だけが未設定なら、成立条件を満たす順位の境目は算出できる。控除後利益は週額の設定後に表示する。明示0円を採用した感度ケースでは、発生対象週数を残し、費用額0円を表示する。現地通貨契約を採用する場合は、各発生週の金額を両案で共通の為替規則によりJPYへ換算する。週によって換算後の円額が異なる場合は、週別換算額を積み上げる。以下の境目の式は円建て週額が全対象週・両案で同額の場合に適用する。[Start Here R11・R12][start]

## 3. 発生週数と代表ケースの検算

`W` は、契約上費用が発生するISO週の集合と報告期間との共通部分の週数。代表例では、両案で予定販売開始週を有償稼働開始週とし、2029-W52末まで連続して有償とする。

| 案 | 報告期間内の発生週（両端を含む） | 件数・週数 |
| --- | --- | ---: |
| 早期案 | 2027-W27〜2029-W52 | **130** |
| 後期案 | 2028-W01〜2029-W52 | **104** |
| 差（早期 − 後期） | この契約仮定で追加となる2027-W27〜2027-W52 | **26** |

| 確認する週・条件 | 早期案 | 後期案 |
| --- | --- | --- |
| 2027-W26（両案の開始前） | 0件 | 0件 |
| 2027-W27（早期の開始週） | `f` 円・1件 | 0件 |
| 2027-W28に販売・納品が0と置く場合 | `f` 円・1件 | 0件 |
| 2028-W01（後期の開始週） | `f` 円・1件 | `f` 円・1件 |
| 2029-W52（両案の最終対象週） | `f` 円・1件 | `f` 円・1件 |
| 2030-W01（報告期間外） | 比較への算入0件 | 比較への算入0件 |

## 4. 控除後の利益と順位の境目

- 早期案の控除後利益 `P早 = P0早 − f × W早`、後期案の控除後利益 `P後 = P0後 − f × W後`。
- `ΔP0 = P0早 − P0後`、`ΔW = W早 − W後`。**控除後の利益差（早期 − 後期）= `ΔP0 − f × ΔW`**。
- `ΔW` は契約上の**費用発生週数**の差。販売開始週の差と同じになるのは、開始条件と継続期間が上の例にそろう場合。

| 条件（`f ≥ 0`） | 比較表の「順位の境目」欄 |
| --- | --- |
| `ΔP0 > 0`、`ΔW > 0` | **`f* = ΔP0 ÷ ΔW` 円／週**。`f` が小さければ早期が上、等しければ同額、大きければ後期が上。 |
| `ΔW = 0` | 「順位変化なし（発生週数が同じ）」。`ΔP0` が0なら両案同額。 |
| `ΔP0 < 0`、`ΔW > 0` | 「正の境目なし（後期が上）」。`f` が増えるほど早期の差は小さくなる。 |
| `ΔP0 = 0`、`ΔW ≠ 0` | 「0円で同額」。正の週額では発生週数の少ない案が上。 |
| `ΔW < 0`、`ΔP0 < 0` | `f* = ΔP0 ÷ ΔW`。`f` が境目を超えると早期が上。`ΔW < 0` かつ `ΔP0 > 0` なら「正の境目なし（早期が上）」。 |
| `ΔP0` または `ΔW` が未確定、比較条件が異なる | 「未算出」と理由を表示。例は「連結利益未評価」「有償週未設定」「共通の円建て週額の条件外」。 |

説明用の仮定として `ΔP0 = 1,300,000円`、`ΔW = 26週` とすると、**境目は50,000円／週**。次の金額は比較表の検算に使う。

| 仮の週額 | 早期の費用（130週） | 後期の費用（104週） | 控除後の利益差（早期 − 後期） |
| ---: | ---: | ---: | ---: |
| 40,000円 | 5,200,000円 | 4,160,000円 | **＋260,000円** |
| 50,000円 | 6,500,000円 | 5,200,000円 | **0円** |
| 60,000円 | 7,800,000円 | 6,240,000円 | **−260,000円** |

実際の2案の `P0`、順位と境目は試行結果待ち。初回の比較表は案別 `P0`、有償開始・終了と `W`、週額と費用額、控除後利益、`ΔP0`・`ΔW`・境目、評価状態を示す。供給不足は配分なしの観測と配分後の未充足を表示し、在庫量・年齢・期末の残り方も併記する。[ロードマップ案 v0.2 §3][roadmap] ・ [初回比較の対応表 §2 #6–#13・§4][mapping]

## 5. 大杉さんの採用判断と受け渡し

| 判断 | 推奨案と選択肢の影響 |
| --- | --- |
| 費用の対象・負担 | **`E_JP` が負担するクリーム販路の週定額運用委託費**を比較用に採用する。契約で有償週が決まり、供給不足で売上が0でも費用が発生する状況を表せる。共通サービスや代理店自己負担が判明した場合は追加負担の範囲を見直す。 |
| どの週から発生するか | **有償稼働開始週**を採用。契約発効時から有償なら発効週、DC稼働時から有償ならDCの稼働週を使う。両案で同じ準備週から同じ終了週まで有償なら `ΔW = 0`。実売開始を条件にする契約なら欠品等による開始の遅れが `W` に効く。 |
| 投入週・契約の終了 | 早期2027-W27を採用するか、有償稼働と予定販売開始を同週に置くか、両案とも2029-W52末まで有償とするかを決める。この仮定では `W早 = 130`、`W後 = 104`。 |
| 週額・評価の用途 | 初回はJPYの週額を感度として表示。実際に適用する週額、通貨・換算、供給水準と在庫保有費の扱いは、試行の採算判断に用いる段階で決める。 |

大杉さんの採用条件をClaude君が初回比較の設計に対応付け、Code君は同一条件の2案の実行結果を照合する。比較表の受入値は、仮定したISO週の130／104週、開始・終了・販売ゼロ週の件数、説明用の境目50,000円／週と3つの差額。配分なしの2案観測は並行して進められる。[ロードマップ案 v0.2 §4][handoff] ・ [初回比較の対応表 §4][comparison]
