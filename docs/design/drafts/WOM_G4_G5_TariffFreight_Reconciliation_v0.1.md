## 1. 価格に含む費用と別に計上する費用

| 照合欄 | G4 日本 → タイ | G5 日本 → シンガポール |
| --- | --- | --- |
| 区間、法人、取引 | `WH_JP_Released → DC_TH`。`E_JP → E_JP` の社内移動。後続の `DC_TH → TH_Distributor` は外部卸売。 | `WH_JP_Released → DC_SG`。`E_JP → E_SG` の法人間取引。 |
| 5,000円／個の用途 | PPCの設定値を、試行で**運賃別の評価用商品単価**に仮採用。課税試算の基礎額120,000円。 | Value Chainの**運賃込みの法人間価格**。`E_SG` の取得額120,000円。 |

| 課税価格・税額 | 推奨する課税価格121,680円。試行税率30%で36,504円、0%で0円。 | 今回の金額照合は法人間取得価格と運賃。現行サンプルには関税0%の入力がある。 |

| 費用の負担と支払 | モデルでは `E_JP` が関税を負担。納付日・支払先・輸入者名義は実際の通関・納付記録で照合。 | モデルでは `E_JP` が外部の運送業者に支払う。船積み時に負担確定と置き、支払週は決済記録で確認。 |

G4の1,680円は課税価格を作るための参照額であり、帳簿では実際の取得費用に対応する。**一つの外部運賃を課税価格の算定と帳簿の両方で参照できる。** 照合では、各課税価格と各原価の内部で、同一費用が一度だけ含まれることを確認する。

## 3. 出荷・費用記録の照合手順

1. **対象を特定する。** 区間、法人の組、`Lot_ID`、元の出荷記録で24個の取引を確認する。出荷記録から受入・販売、G4では通関の記録まで辿る。
2. **元の費用を特定する。** 輸送・保険等の請求番号と明細、費目、費用の対象区間、ロットに配賦された数量と金額を照合する。G4は申告の番号・明細、G5は法人間請求の明細と契約上の包含・負担を結び付ける。
3. **金額と週を突き合わせる。** G4は「課税価格への算入」と「取得原価への関税計上」、G5は「外部請求」と「法人間取得価格」と「連結」をそれぞれ検算する。同じ出荷・費用根拠で再取込や受入を行うときは既存明細と照合し、同じ費用の追加は0件。売上原価への振替は元の在庫原価へ遡る。明示の0円は根拠と一緒に記録し、包含・金額・週が未確認の項目は判定保留とする。
