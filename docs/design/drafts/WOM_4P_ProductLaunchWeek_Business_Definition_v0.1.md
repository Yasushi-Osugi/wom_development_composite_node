# 既存クリームのタイ市場への投入週 業務定義メモ v0.1

## 0 一言で

**既存クリームのタイ投入を2028-W01から2027-W27へ早める二案を、同じ能力・価格・需要生成規則で比べる。早期投入で増える販売機会を、既存市場とタイ自身の後年供給、立上げ・販路維持・在庫資金の負担まで含めて評価する。**

初回は二つの数量計画に限定し、追加増産と新しい配分方針は足さない。供給保護の条件を満たさない場合は未達を記録して採用を保留し、利益だけで早期投入を選ばない。必要な増産は、投入週の効果と分けた次の比較へ回す。

今回新しく決めるのは、投入前の販売機会の扱い、一時費用を含む費用の範囲、守る既存供給と判断方法である。新しい検証は、この業務定義を「施策のシート→投入の表→需要生成→計画・比較・追跡」につなぐことである。

販促の業務採用保留、24週増産は有力候補で最適期間・発注期間ではないこと、保護判定の許容0 lot、店舗費用の100%・50%・0%表示、販促の検証の区切り、次題材は投入週・価格据置、を引き継ぐ。[区切りの判断票][decision] [ロードマップv0.5冒頭][roadmap]

## 1 Q1 経営者が決めたいこと

### 1.1 経営の問い

> 既存クリームをタイの代理店経由で扱い始める時期を早めることで、既存の供給と継続的な販売を守り、立上げ・販路維持・在庫資金の負担に見合う成果を得られるか。得られないなら、投入を待つか、供給枠を別途確保してから再評価するか。

対象は `COS_Cream × TH_Distributor`。製品そのものの仕様・品質・価格・供給経路は維持する。既存品の一市場への投入時期というProductの施策として扱い、新製品の追加や複数市場の投入順序へ広げない。

ブランド、顧客接点、代理店との関係は判断の対象だが、WOMがそれらを金額で推定するわけではない。早く売り始めた後に供給が途切れる影響を、後年の納品・欠品と併記する。

### 1.2 「投入週」の意味

初回の定義は、**タイ代理店の市場側の需要・納品要求が立ち上がる週**とする。需要生成の `launch_week` に対応する。日本での商品発売日、製造開始週、初回の日本出荷週、費用の起算週と同一だとはみなさない。

現行の木ではDC_TH→TH_Distributorに1週のLTがある。市場側で2027-W27に必要な商品は、それより前に製造・移送・DC実出荷され得る。卸売売上は出荷時の支配移転という既存原則を維持し、実出荷週で評価する。**投入前の需要0は、投入前の生産・在庫・費用・卸売計上をすべて0にする規則ではない。**[需要生成関数][generator] [木][tree] [旧観測報告§3 O5][observe]

代理店向けの出荷自体を発売日まで禁止する業務なら、別の条件になる。初回にはその禁止を置かない。

### 1.3 守る供給の条件案

初回は、比較結果に対して次の条件を判定する。下限をエンジンに守らせる新しい配分方針は作らない。

| 対象 | 下限と見る期間 | 判定の扱い |
|---|---|---|
| 投入対象以外の7鍵 | SGのクリーム3チャネルと、美容液4チャネル。**今回の後期基準案の実納品**を、同じ実装・同じ報告期間の下限とする | 早期案の実納品が市場・製品別に下回らない。許容0 lot。2029年内訳・週別も併記 |
| タイのクリームの継続分 | 後期案でも自社需要が発生する2028-W01〜2029-W52の供給。後期案の実納品水準を守ることを推奨 | 早期案の総納品増で、同じ市場の後年供給減を隠さない。追加需要との区分は§5.2 |
| 新しい早期投入分 | 早期に生まれる需要に対する当週納品・遅配・未充足 | 追加需要を全量届けられると事前には約束しない。初回供給見込み・欠品期間を投入判断に示す |

主な保護は期間合計で行う。毎週100%の供給を一律に新設する案ではない。契約受注・納期の約束が分かれば、その対象・期間について別に照合する。下限は試行用の比較基準で、契約数量の認定ではない。

②供給対象へ配分されたことと、④実納品で達成したことは分ける。今回、新たな明示的配分は置かないため、②＝①・③＝0を基本とし、実納品で下限未達なら、業務条件の未達として記録する。実装上の数量不整合とは区別する。

## 3 Q3 投入前の需要はどうなるか

### 3.1 三つの需要を区別する

| 名前 | 意味 | WOMの数量への扱い |
|---|---|---|
| 市場の潜在需要・販売機会 | 自社が参入していなくても市場に存在し得る需要 | 今回は量を推定していない。参入前の自社需要0と、潜在市場0を同一視しない |
| 自社に発生する需要D | 投入週・立ち上がりの仮説から作る自社製品の要求数量 | その案の①元需要。今回の定常3 lotはこの仮定で、市場全体の潜在需要量ではない |
| 供給できなかった需要 | 自社に発生した①のうち、③未配分または⑤未充足になった数量 | ①＝②＋③、②＝④＋⑤で追う。参入前の販売機会をここへ足さない |

**初回は「自社需要を作らない・待ち需要を繰り越さない」を推奨する。** 現行の需要生成規則と一致し、待つ顧客について未確認の行動仮説を足さずに投入週の効果を比較できる。

遅い案で2027年のタイ需要が0なのは、既に発生していた注文を消した結果ではない。需要を作る段階の仮定であり、「未充足が少ないので需要を満たした」とは評価しない。案ごとの①と実納品を並べ、母数が違うことを示す。

### 3.2 需要生成と差の意味

`t`を投入週からの経過週数とする。

```text
t < 0      ：D(w) = 0
0 ≤ t < 13 ：D(w) = ROUND_HALF_UP(3 × 0.5) = 2 lot
13 ≤ t     ：D(w) = 3 lot
```

ここは既存の投入需要生成に合わせた**各週の四捨五入**である。販促の増減分で使った累積切り捨てを転用しない。[demand_for_week][generator]

| 要求年 | LATEの自社需要 | EARLYの自社需要 | 差 |
|---|---:|---:|---:|
| 2027 | 0 | 65 | +65 |
| 2028 | 143 | 156 | +13 |
| 2029 | 156 | 156 | 0 |
| 報告期間合計 | 299 | 377 | +78 |

差78 lotは、2027-W27〜W52の65 lotと、2028-W01〜W13に立ち上がりが既に終わっているため増える13 lotの合計である。**78 lotすべてを「投入前に待っていた顧客」とは扱わない。** これは二つの自社需要仮説の差で、市場全体の機会損失や実際の失注の推計ではない。

### 3.3 待つ顧客を後で扱う場合

初回の待つ割合は明示0とし、実証された値とは呼ばない。待ち需要を追加する場合は、少なくとも次を別の仮説として定義する。

- 待つ候補の母集団と発生週。市場全体の潜在需要か、自社への引合いかを区別する。
- 待つ割合、待てる最大期間、取消・競合への流出、投入後のどの週へ何量を解放するか。
- 通常の立ち上がり需要との包含関係。待ち分を同じ顧客の通常購入へ二重に足さない。
- 報告期間末を超えた解放予定は、期間外の需要として別掲する。期間内へ押し込まず、捨てて全量充足ともしない。
- 発生済みの受注を延期した場合と、未参入の販売機会を仮に将来需要へ換算した場合を分ける。

末を超える量が重要なら、両案とも同じ延長期間で比べる別試行を定義する。初回には需要の単純な26週平行移動や期末後の販売回収を置かない。

## 4 Q4 投入にかかる費用

### 4.1 採用済みのタイ販路維持費から引き継ぐこと

[タイ週固定費の業務定義][thfee]の費目・負担者・有償週の条件は引き継ぐ。

- E_JPが負担する、**クリーム販路の週定額運用委託費**。外部代理店自身が負担する費用は連結対象へ入れない。
- 契約上の有償稼働開始週から終了週まで、両端を含む。有償期間中は納品・売上0でも週1件。
- 代表例は投入週と有償稼働開始週を一致させ、終了は両案2029-W52。開始26週の差で130対104週になる。
- 費用発生週と請求・現金支払週を分ける。報告期間外の販路費は別掲し、報告期間の主比較への算入は0。
- 1案・1契約対象・1費目・1発生週につき1回。同じ週の出荷件数を掛けない。

**既存の採用記録では週額は未設定。** 本書は再定義せず、新しい検証用の低・中・高を提案する。実契約が美容液と共通で、クリームを早めても総額が変わらない場合は、差額となる追加負担を確認する。商品別配賦を新しい外部支出として足さない。

## 5 Q5 評価に入れるものと判断の順

### 5.1 金額と数量の評価表

| 評価 | 初回に入れること |
|---|---|
| P0 | 両案とも同じ2027-W01〜2029-W52のValue Chain消去後連結試算利益。`GROUP/in_report/profit_r2_hq_wk`を週ごとに一度合計。全SKU合計と市場・SKU別の説明を両方残す |
| 外部の費用 | 一時のL、販路維持F、追加の生産枠Rを分ける。PPCやValue Chainに同じ追加費用を重ねて入れない |
| 保有費H | 消去後の連結在庫原価×年率÷52。移送中・助走を含む既存方式で比較調整。助走分と報告期間分を別掲 |
| 数量 | 各案の①元需要・②供給対象・③未配分・④実納品・⑤未充足。元需要が異なるので未充足件数や充足率だけで順位を付けない |
| 供給 | 市場別・要求週別の当週・早出し・遅配・期末未充足、保護条件の達成。2027・2028・2029年を分ける |
| 在庫・品質 | 初回供給、週末在庫・移送中、連結原価の在庫・週、期末在庫、実物の年齢・許容超過。Lot_IDの要求週を実物の製造日とみなさない |
| 資金 | 初回在庫資金、立上げの支払、回収の時差と上限を別に把握。情報不足なら未評価。AをNet Cashと呼ばない |
| 未評価の価値 | 顧客接点・ブランド・取引継続、将来の需要・費用。0円とは置かず、今回の未評価欄へ残す |

比較調整の式は次のとおり。各費用は対象・発生週を明記する。

```text
A = P0_報告期間 − L_報告期間 − F_報告期間 − R_有償週 − H_計画期間
ΔA = ΔP0 − ΔL − ΔF − ΔR − ΔH
```

ここでHは採用済み方式の助走を含む額であり、増産を別途置く場合のRも助走の有償週を含む。したがってAは**意思決定用の比較調整値**で、会計上の報告期間利益ではない。報告期間内の利益と、期間外の準備負担を欄で分ける。タイ販路維持費の報告期間外を主比較へ算入しない既存定義は変えず、該当費用があれば別掲する。

LATEとEARLYでL・fが同じ、追加増産なしなら、初回の式は次になる。

```text
ΔA = ΔP0 − 26f − ΔH
```

同額の一時費用は差で相殺するが、案別のAからは両方とも引く。新しい週額の境目を出す場合は、成立条件を確認して `f*=(ΔP0−ΔL−ΔR−ΔH)/26` とする。過去の340,560円/週を流用しない。未評価費用が残れば、採用可能な境目として確定しない。

### 5.2 タイの継続分と追加分を分ける

今回の需要は、共通期間2028-W01〜2029-W52でも、早期案が13 lot多い。そこで、単に同期間の総納品が後期案以上という判定だけでは、共通する需要への供給を守れたとは言い切れない。

- 基準にするのは、LATEの共通期間の実納品 `F_TH`。
- EARLYの共通期間の実納品から、同期間の追加需要のうち実際に納品された量を引き、継続分の比較数量とする。
- 区分できない場合は、追加需要全13 lotを引いた値を**保守的な下限見積もり**として示す。これがF_TH以上なら数量面の保護を確認できる。下回る場合、すべてが既存分の不足と断定せず「保護未確認」と表示する。
- 追加分のある要求週で全需要が当週に届けば、その週の追加分の納品も確認できる。部分納品の場合の区分はClaude君が数量の出どころとの対応を整理する。
- これは数量上の区分で、既存顧客・新規顧客の個人を特定した判定ではない。顧客別の事実をLot_IDの連番から推測しない。

必要なら2029年分も直接比較する。2029年の①は両案156 lotで同じなので、その年の実納品減は要求年別にそのまま表示できる。期間合計での判断と、契約納期の遵守を混同しない。

| P0と外部費用を分け、基準比を示す | 引き継ぐ |
