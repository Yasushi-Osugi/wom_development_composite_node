- **法人間の価格を基礎にしている別の値**：`ppc_transfer_price_rule.csv` の値は、タイ向けの課税価格の商品価額にも使われています。E2 ではタイの Lot の商品価額が 120,000 → 132,000 円（課税価格 133,680 円）になりました。正式なサンプルの税率は 0% なので関税は 0 のままで、利益には出ていません。工場 → 倉庫の管理上の移動（`management`）の売上も 120,000 → 132,000 円になります（V1 の見方の行で、法人・連結の損益には入りません）。
