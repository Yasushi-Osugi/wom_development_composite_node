### 1.4 差の理由（代表の週と Lot_ID、付録 `compare/*/representative_lots.csv`）

- **C01 → C04：不足が後ろの週へ移る**。
  - 工場は 2 案とも全期間、良品 10 の上限で作り、作った量 1,680 lot は同じ。
  - 強い立ち上がりの 13 週（2028-W01〜W13）の 3 lot は、2 案目では全部当週に届く。例：`COS_Cream:TH_Distributor:2028-W01:00003` は C01 に無い需要で、C04 では 2027-W18 に作られて 2028-W01 に当週出荷。
  - その代わりに、タイの 2029-W17〜W21 の要求週の lot が届かなくなる。例：`…:2029-W18:00001`・`…:2029-W19:00001` は C01 では 2026-W38 に作られて当週に届いていたが、C04 では出荷が無い。
  - 早い週に出る分、在庫は減る（−3.1%）。
- **C03 → C05**：同じ形で、届かなくなるのはタイの 2029-W44〜W50（計画の終わり近く）。
- **C02 → C06：助走の空きで届く**。
  - 全期間増産の案は、2026 年の助走の週に空きがあった。強い立ち上がりでは工場が 2 週早く（2026-W45 → W43）作り始め、13 lot 多く作った（1,768 → 1,781）。
  - 例：`…:2028-W01:00003` は C06 で 2027-W47 に作られて当週に届く。
  - 在庫は ＋3.3%、年齢の最大 25 週。
- **C05 → C07**：増産の窓を 2027-W50 に早めた 13 週で 13 lot 多く作り、C05 で届かなかった 2029-W44〜W50 の lot が当週に届く。例：`…:2029-W44:00003`・`…:2029-W45:00002`。
- 配分の方針は当てていない。届かない lot がどの要求週になるかは、計画のエンジン（Backward の工場の能力の押し戻し）の決め方による。
