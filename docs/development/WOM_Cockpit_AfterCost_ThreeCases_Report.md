### 3.3 境目との関係（保有費の段の数字で読む）

88 週の増産が増産しない案に並ぶ週額は、年率 10% で 110,616 円／週（期間を絞った額で）。中の 46,000 円／週は下、高の 151,800 円／週（割増 0% でも 132,000 円／週）は上なので、§3.1 の並びになる。決め手は依頼書 §0 のとおり、追加の 24 個／週を今の要員の応援でこなせるか（低・中）、専任が要るか（高）。

### 3.4 通常の加工費との重なり（注）

工場の通常の加工費（1 個 600 円、追加 1 lot で 14,400 円）は `P0` に入っている。応援の人件費・洗浄・品質作業がこの加工費にも含まれる場合、その重なりの分だけ確保費が過大（控除後の利益が過小）になる。今回は差し引いていない（大杉さんの判断どおり、注記だけ）。一時費用・最低保証も入れていない。画面の ④ と CLI のまとめにも同じ注を出している。
