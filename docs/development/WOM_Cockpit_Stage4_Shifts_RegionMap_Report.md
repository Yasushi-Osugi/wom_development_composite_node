### 2.4 差の理由（代表の週と Lot_ID）

- 増えた 12,084 lot は、瓶詰の計画値の差（800 − 686 ＝ 114 lot／週）× 上限で作った 106 週。
- 増えた分の行き先：FR +8,160（2027 年 +2,460、2028 年 +5,700）、BE +1,674・NL +1,600（どちらも 2027 年）、JP +300、US_E・US_W 各 +175（2027 年）。
- S01 の欧州の不足は 3 市場とも要求週 2027-W31〜2028-W52 の 74 週にかかっていた。S02 では FR はほぼ解消（残り 2 週・300 lot）。BE・NL は 2027-W47〜2028-W52 の 58 週に不足が残る。
- 代表の lot（付録 `soy/C01__C02/representative_lots.csv`）：
  - `Soy_Sauce:JP:2027-W24:00001`（供給の差が最初に出た要求週）：S01 は出荷なし。S02 は 2026-W32 原料 → 2026-W34 醸造 → 2026-W39 瓶詰を出る → **2027-W18 まで瓶詰の後で在庫** → FG 倉庫 → DC_JP → 2027-W24 に当週出荷。
  - `Soy_Sauce:BE:2027-W32:00001`（差が最大の要求週）：S02 は 2026-W38 に瓶詰を出て、2027-W18 に FG へ、2027-W32 に当週出荷。
  - 増えた能力で作った lot は助走（2026 年後半）の週に作られ、要求週まで在庫で待つ。在庫が 23.7% 増えたのはこのため（在庫の保管費は金額に入っていない）。
- 配分の方針は当てていない。どの市場の要求に増えた分が回ったかは、計画のエンジン（Backward の工場の能力の押し戻し）の決め方による。結果として、量の多い FR と、2027 年の BE・NL・JP・米国に回り、2028 年の BE・NL は残った。
