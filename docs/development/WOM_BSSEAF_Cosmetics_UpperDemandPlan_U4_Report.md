### 2.1 B4 遅配の動き

P2-a2 の遅配は 0（当週 3,856、前倒し 0）。コードで確かめた動きは次のとおり。

- Backward（`_apply_mom_cap_backward`）は、能力を超えた lot を前の週へ押し戻し、最初の週でも入らない分を `past_due` にする。Forward はこれを後の週で作らない。
- Forward が lot を後の週へ送るのは Step 0a（`cap_hard` を超えた分を次の週へ）だけ。今回は平準化の上限が `cap_hard` より低いので起きない（`cap_hard_deferred` 0）。

よって今回の 3 案では、**要求週に間に合わない lot は遅配にならず、そのまま ⑤ になった**。A1 は期間の終わりの能力が余っても（T5）、それで届けることはない。一般に遅配が出ないとは言えない（Step 0a が働くモデルでは出る）。

### 5.1 T3 の差の説明

**A0・A0e の参考値は 0 だが、⑤ は 4・2 ある。A1 は参考値より 21・16 多い。** 差は近似の条件のうち 2 つから来ていた。

1. **最初の週の能力は使えない**：工場の週 0 の需要の計画に置いた lot は、原料の LT 1 週のために作れない（工場の P は週 0 が 0）。診断はこの能力を数えている（美容液 13、クリーム 10）。
2. **直営店は 2 週早い**：`ss_days=14` で、工場への要求が 2 週前に来る。診断は入れていない（累積で美容液 8、クリーム 6）。

この 2 つを外して計算し直すと、**6 通りすべてで ⑤ と一致した**（T3 の右の列）。例：美容液 A1 は 43＋13＋8＝64。⑤ の lot を調べても同じ内訳になる。A1 の美容液 64 lot のうち 13 は週 0 に置かれて作れなかった lot、51 は工場の計画に入らなかった lot（`past_due`）。

これは今回の案と Backward の配置に限った観測で、一般の予測の式としては採用しない（詳細設計 §4）。遅配が 0 だったことが一致の前提にある。

### 5.2 読み取り

- **⑤ の場所**：どの案も代理店（TH）だけに出て、代理店（SG）は全量届いた。どの lot が押し戻されるかは lot の並びの順で決まり、規則も貢献利益も見ていない。
- **A1 の ⑤**：TH の 2029-W21〜W40 に出た。A1 が残すことにした週である。A1 は 2029-W41 以降の代理店の需要を外したのに、それより前の TH が届かない。「近い週を守る」は、選択の上の話に留まった。
- **A1 の能力の余り**：期間の終わりの 20 週で、美容液 116・クリーム 95 lot 余る（A0 は 56・44）。後ろの週の能力は前の週の需要に使えない。
- **A0e と A0**：A0e の ⑤ は 4 で、P1・P2-a1 と同じ水準。A0e は減らす lot を前の週にも散らすので、計画の始めの押し戻しが小さい。年齢の最大は 29 週（A0 は 28）で、52 週超は無い。
- **供給 0**：A0・A0e は 0 週。A1 は SG が 2029-W41 からの 12 週、TH が最長 16・18 週。TH は SG より先に止まる。
