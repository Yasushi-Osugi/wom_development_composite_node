### 2.3 行の順の入れ替え（不変性）

C03（`balance_cut_ratio`、元の木）と C04（同、兄弟の順を逆にした木）を比べた：

| 項目 | 結果 |
|---|---|
| snapshot（forward・backward・ppc・psi） | 同じ |
| 市場別の ①〜⑤・年別 | 同じ |
| 実出荷の Lot_ID と週（3,864 件、digest `cd5518ddfe5e3132`） | 同じ |
| 工場 × 市場の延べの押し戻し・母数、計画の前に落ちた lot の市場別 | 同じ |

| Lot_ID で数えた滞留の最大（`lot_dwell_max`、チャネル別） | 同じ |
| **先入れ先出しの年齢の最大**（年齢の検査） | **28 → 27 週**（分布も違う） |

- 年齢の差の理由：`tools/shelf_life_check.py` は、同じ週に同じ場所（DC）から出ていく兄弟の市場を、木の行の順（`NodeInfo.rank`）に処理し、古い札から順に渡す。

- `tail` の入れ替え（C05）でも同じことが起きる（C01 28 週・C05 27 週。こちらは計画も違う）。
- このため、止める理由「入れ替えで `balance_cut_ratio` の結果が変わる」には当たらないと判断した。年齢の検査を行の順に依らない数え方にするかは、別の判断として残す。

## 5. 気づいたこと

1. **総納品は、ここで回した全部で方式に依らなかった**：
   - 化粧品 3,864、醤油 C03 87,344、醤油 alloc 75,291、golden 13 モデルの当週・遅配・注文残の合計。
   - 毎週はみ出す数と、計画の前に落ちる数は方式で変わらず、変わるのは市場への分け方。
2. **販売開始のずれがある場（化粧品）での二つの新方式の差**：
   - ④÷① の開き：`proportional_week` 4.65〜4.90、`balance_cut_ratio` 4.54〜5.44 ポイント。製品によって大小が逆。
   - `balance_cut_ratio` は累積押戻負担率を 17.96〜18.28 にそろえる。`proportional_week` は 16.98〜18.95。
   - 負担率をそろえても ④÷① はそろわない。押し戻された lot が前の週で作れたかどうかは、市場ごとに違うため。
3. **タイの代理店（2028 年から販売）**：
   - `proportional_week` は、その週の並びにある数に比例して押し戻す。タイの代理店は母数が少なく、負担率が最も低い（16.98・17.10）。④÷① は 98.7% で最も高い。
   - `balance_cut_ratio` では負担率が他の市場とそろい、④÷① は 91.6%・93.6%。
4. **金額**：
   - 化粧品の P0 は `tail` が最も高い（606.9 百万円）。新しい方式は 600.7・601.1 百万円。
   - 醤油 alloc の PPC 粗利は新しい方式が高く、P0 は `tail` が高い。
   - どれも、納品の市場が入れ替わり、市場ごとの単価・費用が違うため。保有費が未設定のモデルでは、在庫の増減は P0 に入っていない。
5. **年齢の検査の順**（§2.3）：計画が同じでも、木の兄弟の順で先入れ先出しの年齢の最大が 1 週違う。
6. **golden を作り直す範囲**：
   - 既定を新しい方式に替えると、snapshot が変わるのは oil・soysauce-jpy-2027-alloc・smartphone の 3 モデル（各方式とも）。
   - 段 0 の「変わる見込み 13」より少ない。段 0 は押し戻しが起きる工場を数えたもので、snapshot が変わるかは見ていなかった。
   - legacy の golden 3 つは今回の対象外で、回していない。
