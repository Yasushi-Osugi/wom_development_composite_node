### 5.2 読み取り

- **能力が余らなかった**：期間の終わりの 30 週の余りは A3 が美容液 52・クリーム 40、A0e が 54・42。どちらも余りのほとんどは最後の 4 週で、A3 は 2029-W47・W48 の余りが 0 になった。A1 の 20 週の余りは 116・95 lot だった（前回）。
- **選んだ週に届いた**（T10）：A3 は当週の割合が 100%。A1 は同じ ② で 119 lot が残した週に届かなかった。違いは、外す量を「その週の能力を超える分」に限ったことである。
- **⑤ と充足率のやりとり**：合計の充足率は A3 が一番良いが、差は 95.27% と 95.17% で小さい。大きく違うのは分布で、A0e は全期間で 92% 前後、A3 は前半 100%・後半 60〜75%。
- **SG の減り方が大きい**：後半の充足率は TH の 75.0%・74.0% に対して SG は 62.5%・60.6%。鍵の間を残りの減らす量に比例で分けるので、数量枠で多く減らす SG に多く寄る。
- **期間の終わりの 2 週**：2029-W51・W52 は全量を残した。その週の必要が能力を超えなかったからで、A3 の代理店の供給はこの 2 週だけ急に戻る。直営店の要求は 2 週早いので、工場の 2029-W47・W48 に直営店の必要が無いためで、需要データの終わりから生じる形である。
- **年齢**：最大 28 週で A0 と同じ、52 週超は無い。

## 6. 止める理由と申し送り

**止める理由：無し。** 往復は 0 回。

申し送り：

1. **A3 は計画の終わりを知っている**：減らす週は期間の終わりから決めるので、需要の期間を延ばすと選び直しになる。計画を毎期作り直す運用での動きは調べていない。
2. **条件 2 つは化粧品で確かめたもの**：`first_week_unusable=True`・`ss_lead=True` を規則の既定にしたのは依頼書のとおり。他のモデルでは確かめていない。工場が 2 つ以上の SKU は適用外で、減らす量があれば止める。
3. **比例の分け方**：鍵の間の分け方は設計どおりで、貢献利益も優先も見ていない。SG に寄ることが業務上よいかは未判断。

5. **Lot_ID の滞留**：A3 は最大 143 週、52 週超が 447 lot。前回と同じく年齢とは別の数で、原因は調べていない。
