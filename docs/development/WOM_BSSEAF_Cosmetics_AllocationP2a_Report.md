**結果の読み方**：

- 案の間の差が小さいのは、変わるのが**貢献利益のほとんど同じ代理店の間だけ**だから（美容液 5,712.50 と 5,682.50、クリーム 4,730.00 と 4,671.50）。直営店・EC は 3 案とも全量を満たす。**この事例では、配分の基準の違いが利益に与える影響は小さく、どの代理店を減らすかは、利益より業務の判断（タイという新しい市場に入る意味、代理店との約束）で決まる種類の問題**である。
- **差が小さいこと自体が結果**である（依頼書 §0）。P2-a1 と P2-a2 の差 -559,380 は、組の中で需要に比例して配る（両方の代理店を少しずつ減らす）という**安定した配分のために受け入れた利益の差**に当たる。ただし今回はその大半（501,240）が、比例して減らした結果として計画の最後の週の需要が下がり、工場の最後の 2 週の能力が使えなくなった境界の効果であって、配分の基準そのものの差（見込み −58,140）ではない。
- タイの関税が 30%（M4 の感度）なら、美容液の代理店（TH）の貢献利益は 3,912.50 円（クリーム 3,230.00 円）になり、順位が入れ替わる。P2-a1・P2-a2 の規則とも、**P1 と同じ配分**（タイから減らす）になることを確かめた（§3.5 の T11）。

## 6. 止める理由と申し送り

**止める理由**：無し（§2.1 の貢献利益は再現した、§2.3 の配分は見込みと一致した、道具は不整合なしで終わった、期間・能力の固定は保たれた、Part A の既定の動きは変わらない）。

**申し送り**：

1. **⑤ は配分を週に散らす端数で変わる**（P2-a2 で 4 → 8）。どの代理店から減らすかが同じでも、両方を少しずつ減らすと、計画の最後の週の端数の効果が両方に出る。比べる案の間で ⑤ がそろわないと、評価の額の差に配分の基準と関係の無い成分（今回 501,240）が入る。どの週から減らすかを業務の規則として持つなら、配分のファイルに期間の列（週ごとの `alloc_lots`）が要る（P0・P1 の申し送り 3 と同じ論点）。案を比べるときは、評価の額を ③ の逸失と ⑤ の逸失に分けて読む（T9）。
2. **P2-a2 の組の閾値 5%** は依頼書の値。今回は代理店 2 つだけが組になった（差 0.5%・1.2%）。閾値の業務上の意味（何%なら「同じ」と見るか）は決めていない。
3. 評価の額の固定費の相当額（213,719,220）は M0 の値で凍結した。配分で直営店・EC の数量は変わらないので今回の比較には影響しないが、直営店・EC の数量が変わる試行（P2 の先）では、固定費をどう置くか（金額仮定書 §7）を先に決める必要がある。
4. 数量配分モードは PPC を呼ばない（`valuation: 未評価`）ので、P2-a の案の PPC の試算利益は計算していない。評価の額は貢献利益の単価と ④ からの比較値である。
