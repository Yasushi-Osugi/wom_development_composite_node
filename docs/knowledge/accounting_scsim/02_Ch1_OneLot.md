# 第 1 章 E2E のコスト構造 — 1 ロットの一生と金額（説明案）

## 1. 経営の問い

> シンガポールの公式 EC で売れたクリーム 1 ロット（24 個）は、原料から顧客に届くまでに、どこでいくらの原価と費用がかかり、誰の利益になり、グループとしていくら残ったのか。

## 2. 登場するもの（例題のモデル）

| もの | 中身 |
|---|---|
| 法人 | 日本本社（連結、円）、シンガポール販社（連結、シンガポール・ドル）。原料の供給者と、両国の代理店は外部 |
| 流れ | 原料（日本、外部） → 工場（日本本社） → 出荷判定済み倉庫（日本本社） → シンガポールの DC（販社） → 公式 EC（販社） → 消費者 |
| 1 ロット | 24 個 |
| 前提（モデルの仮定） | 1 シンガポール・ドル ＝ 115 円（一定）、価格は税抜、シンガポール向けの関税は 0、日本本社の研究開発・グローバルなブランド費用・歩留まり損の原価・法人税は含めない |

**見る前の約束**：以下は、化粧品サンプルの業務条件に対して WOM が採用した費用の分け方（`wom/valuechain/policy.py`）による試算である。費目の名前やグループの内外だけで、すべての企業に同じ会計処理が当てはまるわけではない。金額は特に断らない限り **1 個あたり**。1 ロットの金額は §3.5 の表にまとめる。

## 3. 1 個あたりの金額をたどる（円）

### 3.0 このロットの週の流れ（実際の計画の出力）

代表のロット `COS_Cream:SG_EC:2028-W30:00001`。

| 段 | 週 | 持ち主 |
|---|---|---|
| 原料の仕入 | 2028-W25 に出て W26 に工場へ | 日本本社 |
| 製造 → 出荷判定済み倉庫 | W26 に作り、W27 に倉庫で受け入れる | 日本本社 |
| 法人間の出荷（倉庫 → シンガポールの DC） | W27 に出て W29 に着く（海上 2 週） | 出荷の週から販社 |
| DC → 公式 EC | W29 に着いたその週に出て、W30 に着く | 販社 |
| 消費者への販売 | W30（着いたその週） | 販社 |

### 3.1 日本本社の中（作って、倉庫に置く）

| 段 | 金額（1 個） | 会計の扱い |
|---|---:|---|
| 原料の仕入（外部から） | 1,300 | 在庫原価 |
| 工場の加工費 | 600 | 在庫原価（通常の加工費の近似） |
| 工場 → 倉庫の運賃 | 20 | 在庫原価（在庫を所定の場所へ運ぶ費用） |
| 倉庫の保管・出荷処理 | 30 | **その週の期間費用**（受入のときに 1 回。毎週かかるわけではない。在庫原価に入らない） |

### 3.2 シンガポールへ売る（法人間の取引）

- 法人間の価格は 1 個 5,000 円。取引条件は CIF 型（日本本社が海上運賃 60 円を負担し、価格に含む）。
- 日本本社：法人間売上 5,000、対応する原価 1,920（1,300 ＋ 600 ＋ 20）＋ 海上運賃 60 ＝ 1,980。粗利益 **3,020**。
- シンガポール販社：在庫原価 5,000（運賃を再び足さない）。DC の取扱・通関 0.5 ドル（57.5 円、取得関連費用の近似）を足して 5,057.5。

### 3.3 まだ外部に売れていない間（週末の在庫）

法人間の出荷の週（W27）から外部販売の週（W30）までの週末、このロットは**海の上か、DC から EC へ向かう途中**にある。この例のモデルでは、DC にも EC にも着いたその週に次へ送られるので、DC や EC の棚で週末を越すことはない（公式 EC のクリームの 299 ロットすべてで同じ）。

| 週末 | 所在 | 販社の帳簿（1 個） | 連結（1 個） | 内部の利益（1 個） |
|---|---|---:|---:|---:|
| W27・W28 | 倉庫 → DC の輸送中 | 5,000 | 1,980 | 3,020 |
| W29 | DC → EC の輸送中 | 5,092（DC の取扱 57.5 と EC への運賃 34.5 を足した後） | 2,072 | 3,020 |

**差額 3,020 円が在庫に含まれる内部の利益（未実現利益）で、連結では消去する。** 外部売上がまだないので、このロットの連結の粗利益は 0 円。

一方、日本の倉庫の期間費用 30 円は、発生した週に費用になっている。その費用を含めた、外部に売れる前のここまでの累計の損益は、ほかの費用を除けば −30 円（1 ロットで −720 円）。すでに計上した 720 円を、その後の保管の週ごとに再び計上はしない。

| | 法人別の見え方 | 連結の見え方 |
|---|---|---|
| 在庫の金額 | 販社の在庫 5,000（W27・W28）→ 5,092（W29） | グループの原価 1,980 → 2,072（内部の利益 3,020 を消去） |
| 粗利益 | 日本本社に 3,020（法人間の販売の週） | 0 |
| 期間費用 | 日本本社の倉庫 30（発生した週） | 30 |

- 「今週の損益」と「ここまでの累計」は分けて読む。倉庫費を計上した週より後で何も起きていない未販売の週なら、その週だけの費用は 0 円。
- 期末在庫は、所在と、そこまでに積んだ原価を対応させる。DC で受け入れた直後の 5,057.5 円（連結 2,037.5 円）は、同じ週のうちに EC へ送られるので、週末の残高としては現れない。
- 実際の会社で DC の棚に週末を越して在庫がある場合も、考え方は同じ（所在が DC、積んだ原価がそこまで）。

### 3.4 公式 EC の外部販売と、ロット全期間の採算

| 項目 | 1 個 | 扱い |
|---|---:|---|
| 売上（131 ドル） | 15,065 | 外部売上（販社） |
| DC → EC の運賃（0.3 ドル） | 34.5 | 在庫原価（販社の中の区間） |
| 売上原価（販社） | 5,092 | 5,057.5 ＋ 34.5 |
| 販社の粗利益 | 9,973 | |
| 消費者への配送・梱包（3 ドル） | 345 | 販売費（発送の週） |
| 販社共通管理費（売上の 10%、近似） | 1,506.5 | 販売費（売上の週） |
| 決済・EC 基盤手数料（5%） | 753.25 | 販売費（売上の週） |
| デジタル広告（15%） | 2,259.75 | 販売費（売上の週） |

外部販売の週には、連結で売上 15,065 円、売上原価 2,072 円（2,037.5 ＋ 34.5）、粗利益 **12,993 円**を認識する。以前に消去していた内部の利益 3,020 円が、外部販売にともなって実現する。日本本社が同じ法人間売上をもう一度計上するわけではない。

売上比率の 3 費目 4,519.5 円と配送・梱包 345 円がこの販売の週に計上され、日本の倉庫の 30 円が以前の週に計上済みなら、**この販売の週の連結の試算損益は 8,128.5 円**（1 ロット 195,084 円）。

日本の倉庫の期間費用も含め、製造から外部販売までの本例の費用を通算した採算は **8,098.5 円**（1 ロット 194,364 円）。これはロット全期間の試算の採算であり、日本本社の研究開発・グローバルなブランド費用、歩留まり損の追加原価、法人税などを含む最終の利益ではない。

**確かめ**：日本本社 3,020 ＋ 販社 9,973 ＝ 連結の粗利益 12,993。これは**このロットの各法人の粗利益を、それぞれの認識の週にまたがって通算した照合**として正しい（日本本社の過去の粗利益を当週に足すという集計ではない。週ごとには、未実現利益の増減を通じてつながる）。法人間の価格 5,000 円は、法人別の利益の分け方を決めるが、連結の粗利益には出てこない。

報告期間の開始前に倉庫費が発生したロットでは、その報告期間の P0（連結の試算利益）とロット全期間の採算は、この期間の差でも一致しない。

## 4. 数量編とのつながり

- どの週に作り、何週に DC に着き、何週に売れたかは、WOM 数量編（ロットの PSI）が決める。売れるまでの週数が長いほど、在庫に残る期間（§3.3）が長くなる。
- 能力が足りない週に押し戻されたロットは早く作られ、在庫の期間が延びる（在庫の保有費、第 7 章）。

## 5. 財務会計と管理会計

- 財務会計の見方：法人別の損益（日本本社・販社）と連結の損益。期末在庫の内部の利益を消すのは、連結の手続き。
- 管理会計の見方：製品 × 市場の採算（公式 EC のクリームはいくら残るか）、打ち手の差額（第 7 章）。同じ Value Chain の連結の数字を、判断にも使う。
- PPC と Value Chain は計算・集計の方式の違いで、どちらも管理会計の判断に使える。Value Chain も財務会計の全体を実装したものではない。

## 6. 別の道：タイの代理店へ売るロット（比較のための短い例）

タイの DC は日本本社と同じ法人に属するので、日本本社から DC への移動で法人間の売上は生じない。関税の評価用の商品価額は、モデル上の振替価格の設定 5,000 円を参照し、別建ての運賃 70 円を一度だけ加える。この 5,000 円は、ここで実際の法人間の売買があることや、税務上認められる価格であることを意味しない。

正式なサンプルの税率は 0%。仮に 30% にすると、課税価格 5,070 円 × 30% ＝ 1,521 円、24 個で 36,504 円の関税になる。モデルは受入の週を通関確定の週の代わりにして、関税を在庫原価に加える。そのロットの外部販売のときに売上原価が増えて、連結の試算利益が下がる。関税を在庫原価と期間費用の両方で引かない。支払いで現金が減る週は、この試算では決めていない。

- 照合の結果（確認問題 E3）：関税 36,504 円が DC の受入の週（W29）に在庫原価として 1 回入り、同じ週の卸売の売上原価が同じ額だけ増えた。この例のモデルでは DC に着いた週に卸売されるので、関税を含んだ在庫が週末に残る様子は見えない。モデル全体の連結の試算利益は 10,914,696 円減った。
- PPC で同じ条件を計算すると、減り方は 10,764,000 円で、150,696 円少ない。PPC は課税価格に運賃 70 円を含めないため（計算方式の違い。どちらが正しいかではなく、課税価格の定義の違い）。
- **落とし穴**：タイ向けの関税の参照価額 5,000 円は、シンガポール向けの法人間の価格（`vc_price_rule.csv`）ではなく、工場の振替価格の設定（`ppc_transfer_price_rule.csv`）から来ている。「移転価格」の設定が二つのファイルにあるので、片方だけ変えると食い違う（確認問題 E2 で、こちらを 5,500 円にするとタイの課税価格も 5,500 円を基礎に動いた）。

## 7. 落とし穴と、できないこと

- 倉庫の保管・出荷処理費を在庫原価に入れると、期末在庫と売上原価の週がずれる（WOM は受入時 1 回の期間費用）。毎週の保管料や、資本の拘束（在庫の保有費）とも別のもの。
- 同じロットの法人間売上と外部売上は別の取引。連結で二重に数えない。1 個あたりの金額を 1 ロットの金額として引用しない。
- 未販売の期間の損益を「いつも 0」または「毎週 −720 円」と説明しない（単週・累計・全期間を分ける）。
- 在庫原価の計算方法（先入先出・平均）は選べない（ロットごとの個別の原価）。法人税・為替換算差額・資金繰りは扱わない。

## 8. 照合の結果と、残っていること

- **照合済み**（Code君、`docs/development/WOM_Knowledge_Ch1_OneLot_Reconcile_Report.md`）：§3.5 の全部の金額、週末の残高（輸送中）、タイのロット、確認問題 E2（法人間の価格 5,500 円：連結の粗利益・全期間の採算・P0 は変わらず、日本本社と販社の分け方だけが動く）と E3（関税 30%）。
- E2 で、法人別の利益の合計（消去前）は 108,000 円減った。報告期間の初めに持っていた在庫の内部の利益が増えた分（9 ロット × 12,000 円）で、連結（消去後）は変わらない。
- 販社共通管理費 10% は、販社自身の共通管理費の近似と定義した（判断票 P1）。
- **数え方の注意**：明細には法人間・管理上の移動の売上の行もある。連結の売上は「外部（`scope=external`）」の行だけで読む（評価の基準の列だけで集計すると、法人間の売上まで入る）。
- 残っていること：確認問題 E1（受入時に支配が移る消費者向け取引）は、今の WOM の設定では実行できない。業務上の期待結果として扱い、実行の経路は別の設計課題。
