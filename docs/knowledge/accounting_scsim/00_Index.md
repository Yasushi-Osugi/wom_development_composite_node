# 会計とサプライチェーン・シミュレーション — WOM の知識体系（目次）

**第一の読み手**：経営者と経営学を学ぶ学生（実務家は第二の読み手）。**例題**はすべて架空のモデル（主に化粧品 `cosmetics-sg-th-2027-2029`）。税務・会計の助言ではない。

## 構成

| 部 | 章 | 経営の問い | 状態 |
|---|---|---|---|
| 序 | 序章 WOM とは何か | 週とロットで、経営の打ち手の結果をどう確かめるのか。「カスタマイズ・フリー」とは。第 7 章の問いの予告（例：発売を早めたら、届く数量・利益・先行在庫はどう変わるか） | 未着手 |
| 序 | 第 0 章 数字の読み方 | 同じ 1 ロットに、物流・法人別・連結・経営判断の四つの答えがある。設定した範囲の連結試算利益（P0）と、意思決定用の比較値（A）。単位（lot／個、SGD／JPY）、単週／累計／全期間、未設定／明示の 0／未評価。利益と現金。WOM にできないこと | 未着手 |
| 一 | **第 1 章 E2E のコスト構造（1 ロットの一生と金額）** | 原料から顧客まで、どこでいくらの原価・費用がかかり、誰の利益になるか。未実現利益の意味をここで短く説明する（詳しくは第 6 章） | **説明案・数字は照合済み** `02_Ch1_OneLot.md` |
| 一 | 第 2 章 価格 | 市場ごとの価格と通貨は、売上と利益にどう効くか（価格の変更と弾力性は業務定義が先） | 未着手 |
| 二 | 第 3 章 Value Chain（法人・取引条件・内部取引） | どの法人が持ち、売り、負担するか。取引条件（CIF など）で何が変わるか | 未着手 |
| 二 | 第 4 章 関税 | 何に税率を掛けるか（課税価格）。誰が、いつ負担するか | 未着手 |
| 二 | 第 5 章 移転価格 | 法人間の価格を変えると、法人別の利益・関税・連結の利益はどう動くか | 未着手 |
| 二 | 第 6 章 連結会計 | 内部取引と、在庫に残る内部の利益をどう消すか。報告通貨と為替 | 未着手 |
| 三 | 第 7 章 経営コックピットで打ち手を比べる | 販促・投入週・増産を、同じ条件の対照と比べ、差の理由をたどる（販促の試行 1〜4b、投入週の 1・2 本目） | 未着手 |

| 付録 | 中身 | 状態 |
|---|---|---|
| A | 用語の対応表（会計の概念 ↔ WOM の表し方 ↔ 確認済みの範囲 ↔ 簡略化・未対応） | **草案** `01_Term_Map.md` |
| B | 例題のモデルのデータ（化粧品の法人・ノード・価格・費用） | 未着手 |
| C | 落とし穴（実際に起きた誤り） | Start Here §4.3 から起こす |
| D | 検証の記録への索引（業務定義・報告書） | 未着手 |
| E | 別の条件での確認問題。E1 受入時に支配が移る消費者向け取引、E2 法人間の価格だけを変える、E3 関税を 0% から 30% に。各問に固定条件・期待結果・追加確認事項・WOM での実行の確認状態を置く（期待結果は GPT-MC君のレビュー §7） | 問いと期待結果あり。E2・E3 は Value Chain で実行して確認済み、E1 は今の WOM では実行できない |

## 各章の型（定義書 §3.2）

1. 経営の問い 2. 財務会計では 3. 管理会計では 4. WOM 数量編では 5. WOM 金額編では 6. 例題（代表の 1 ロットを手計算でたどる。外部に売れる前の期末在庫の期間を含む） 7. 落とし穴と、できないこと

## 知識の項目に残すもの（定義書 §3.5）

定義・適用の条件・WOM との対応・期待結果・検証の根拠・採否と確認の状態。
