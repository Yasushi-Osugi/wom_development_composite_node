# 第 1 章 E2E のコスト構造 — 1 ロットの一生と金額（説明案）

## 1. 経営の問い

> シンガポールの公式 EC で売れたクリーム 1 ロット（24 個）は、原料から顧客に届くまでに、どこでいくらの原価と費用がかかり、誰の利益になり、グループとしていくら残ったのか。

## 2. 登場するもの（例題のモデル）

| もの | 中身 |
|---|---|
| 法人 | 日本本社（連結、円）、シンガポール販社（連結、シンガポール・ドル）。原料の供給者と、両国の代理店は外部 |
| 流れ | 原料（日本、外部） → 工場（日本本社） → 出荷判定済み倉庫（日本本社） → シンガポールの DC（販社） → 公式 EC（販社） → 消費者 |
| 1 ロット | 24 個 |
| 為替（モデルの仮定） | 1 シンガポール・ドル ＝ 115 円 |

## 3. 1 個あたりの金額をたどる（マスターからの手計算、円）

### 3.1 日本本社の中（作って、倉庫に置く）

| 段 | 金額（1 個） | 会計の扱い（`policy.py`） |
|---|---:|---|
| 原料の仕入（外部から） | 1,300 | 在庫原価 |
| 工場の加工費 | 600 | 在庫原価 |
| 工場 → 倉庫の運賃 | 20 | 在庫原価（グループの中の区間） |
| 倉庫の保管・出荷 | 30 | **その週の期間費用**（在庫原価に入らない） |

### 3.2 シンガポールへ売る（法人間の取引）

- 法人間の価格は 1 個 5,000 円。取引条件は CIF（日本本社が海上運賃 60 円を負担し、価格に含む）。
- 日本本社：法人間売上 5,000、対応する原価 1,920（1,300 ＋ 600 ＋ 20）＋ 海上運賃 60 ＝ 1,980。粗利益 **3,020**。保管 30 は期間費用。
- シンガポール販社：在庫原価 5,000。DC の取扱・通関 0.5 ドル（57.5 円）を在庫原価に足して 5,057.5。

### 3.3 まだ外部に売れていない間（期末在庫）

| | 法人別の見え方 | 連結の見え方 |
|---|---|---|
| 在庫の金額 | 販社の在庫 5,057.5 | グループの原価 2,037.5（1,980 ＋ 57.5） |
| 利益 | 日本本社に粗利益 3,020 | **内部の利益 3,020 を消去**。粗利益 0 |

グループの外にはまだ何も売れていないので、連結の利益は 0。法人別では日本本社に利益が出ている。この差が「在庫に残る内部の利益（未実現利益）」で、WOM はロットごとに記録する（`ledger.py` の eliminated）。

### 3.4 公式 EC で消費者に売れた週

| 項目 | 1 個 | 扱い |
|---|---:|---|
| 売上（131 ドル） | 15,065 | 外部売上（販社） |
| DC → EC の運賃（0.3 ドル） | 34.5 | 在庫原価（販社の中の区間） |
| 売上原価（販社） | 5,092 | 5,057.5 ＋ 34.5 |
| 販社の粗利益 | 9,973 | |
| 消費者への配送・梱包（3 ドル） | 345 | 販売費 |
| 売上に比例する費用（販管費の配賦 10%・決済手数料 5%・広告 15%） | 4,519.5 | 販売費 |

| | 法人別の見え方 | 連結の見え方 |
|---|---|---|
| 粗利益 | 販社 9,973（日本本社の 3,020 は前の週に計上済み） | 売上 15,065 − グループの原価 2,072（2,037.5 ＋ 34.5）＝ **12,993**（内部の利益 3,020 が実現） |
| 費用を引いた後 | 日本本社 3,020 − 30、販社 9,973 − 345 − 4,519.5 | 12,993 − 30 − 345 − 4,519.5 ＝ **8,098.5** |

**確かめ**：連結の粗利益 12,993 ＝ 日本本社 3,020 ＋ 販社 9,973。法人間の価格 5,000 は、法人別の利益の分け方を決めるが、連結の粗利益には出てこない。1 ロット（24 個）では、連結の費用を引いた後で 194,364 円。

## 4. 数量編とのつながり

- どの週に作り、何週に DC に着き、何週に売れたかは、WOM 数量編（ロットの PSI）が決める。売れるまでの週数が長いほど、在庫に残る期間（§3.3）が長くなる。
- 能力が足りない週に押し戻されたロットは早く作られ、在庫の期間が延びる（在庫の保有費、第 7 章）。

## 5. 財務会計と管理会計

- 財務会計の見方：法人別の損益（日本本社・販社）と連結の損益。期末在庫の内部の利益を消すのは、連結の決算の手続き。
- 管理会計の見方：製品 × 市場の採算（公式 EC のクリームはいくら残るか）、打ち手の差額（第 7 章）。同じ Value Chain の連結の数字を、判断に使う。

## 6. 別の道：タイの代理店へ売るロット（比較のための短い例）

- タイの DC は日本本社の持ち物なので、日本本社 → タイの DC は法人間の売上にならない（内部の利益は生じない）。
- タイの代理店（外部）への卸売で、日本本社が外部売上を立てる（1 個 1,600 バーツ）。
- 輸入の関税の課税価格は、移転価格 5,000 円 ＋ 運賃 70 円（G4）。正式なサンプルの税率は 0% なので関税は 0。税率を置くと、関税は外部への支払いなので連結の利益も下がる（第 4 章・第 5 章）。

## 7. 落とし穴と、できないこと

- 倉庫の保管費を在庫原価に入れると、期末在庫と売上原価の週がずれる（WOM は期間費用）。
- 同じロットの法人間売上と外部売上は別の取引。連結で二重に数えない。
- 在庫原価の計算方法（先入先出・平均）は選べない（ロットごとの個別の原価）。法人税・為替換算差額・資金繰りは扱わない。

## 8. 照合の予定（Code君に依頼する）

1. 公式 EC のクリームの代表のロットを 1 つ選び、Value Chain の明細から、§3 の各段の金額・週・法人を取り出して手計算と照合する（24 個ぶん）。
2. そのロットが期末在庫だった週（DC にあって未販売）の、法人別の在庫と内部の利益の残高。
3. タイの代理店へのロットを 1 つ（§6）。税率 30% の感度の写しで、関税と連結の利益の動き。
4. **GPT-MC君に確かめたいこと**：費目 `hq_sga_allocation`（「販社販管費 10%」）は、販社自身の販管費か、本社からの配賦か。本社からの配賦なら、連結では内部の取引として消える性質のもので、§3.4 の連結の費用に入れるのは誤りになる。
5. 別の条件での確認問題の材料：「受入時に支配が移る契約なら、§3.4 の売上の週と期末在庫の扱いがどう変わるか」。
